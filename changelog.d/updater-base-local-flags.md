- Auto-update PR base: new policy key `auto_update_pr_base` (default empty = `origin/HEAD` as before) names the branch the `perun/update-v<ver>` PR targets and the committed-version WARN compares against. A named base missing on origin skips with `pr skip: auto_update_pr_base '<b>' not found on origin`, never guessed.
- Install flags: machine-local flags (`--with-operating-layer`, `--apply-operating-layer`, `--no-operating-layer`, `--no-sandbox`, `--no-auto-update`) are now recorded in the untracked `.claude/.dcr-install-flags.local` (excluded via `.git/info/exclude`), so a committed record no longer replays one machine's choice on every clone. Pack flags stay in the tracked `.dcr-install-flags`. `update-installed.sh`, `perun_doctor.py` and the uninstaller read/remove both; an old tracked file that still holds local flags keeps working and is split on the next install or update.
