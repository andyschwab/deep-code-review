### Added
- `token_report.py --project DIR` now prices each auto-loaded instruction file lanes re-read: project `CLAUDE.md`, `AGENTS.md`, `.claude/CLAUDE.md`, the user-level `CLAUDE.md` (from `CLAUDE_CONFIG_DIR` or `~/.claude`) and the project memory `MEMORY.md`. Size is file bytes / 4 (an estimate; contents are never read) and the upper-bound input-eq a file contributes is tokens x (1.25 per lane start + 0.1 per later lane turn) summed over lanes. `AGENTS.md` and memory are labelled "if loaded". `--json` gains `startup_files`; the text report prints the top 3 and, when half of the largest file's cost (an assumed trim fraction) is 5% or more of main plus lane input-eq, a "trim or split <file>" lever that also enters `lever_ranking` as an estimate-labelled "trim <file>" row (`estimate: true`). It also reports `startup_remainder`: measured lane startup minus the file estimate (system prompt, tool/MCP definitions, skill listing, brief; not split further) as tokens, input-eq, and shares of lane startup and lane input-eq; when it is over half of lane startup and at least 15% of lane input-eq a Lever line points to the MCP-unused / tool-search advice, batching short lanes and a smaller toolset per lane type. Both are skipped (`startup_files` empty, `startup_remainder` null, a note printed) under `--since`, where a windowed lane's first turn is not its start. Lane records gain `turns`. Tests: `scripts/test_token_startup_files.py`.
