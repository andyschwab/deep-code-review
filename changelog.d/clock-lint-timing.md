### Added
- `clock_lint.py` gains a `timing bet under load` rule for Python tests: inside a `test_*` function (or any function in a file under `tests/` of the repo-relative path) it flags `time.sleep(<positive number>)` followed later by an assert (not in a sibling `if`/`else` branch), a `run`/`call`/`check_call`/`check_output`/`communicate`/`wait`/`get` call with `timeout=<number <= 5>`, and `assert <X> < <number>` where X is an `elapsed`/`duration`/`latency`/`took`/`runtime`/`wall` name or call, or arithmetic on `time.time`/`monotonic`/`perf_counter`. The `clock-lint: allow` escape (any line of a multi-line call), `COULD_NOT_CHECK` and `--base`/`--head` scoping are unchanged; a crash in the rule is `COULD_NOT_CHECK` (exit 2). The new `--block-added` flag (needs `--base`) makes only a timing bet in a file added in the range exit 1; everything else still prints as a warning. The pre-push hook template runs clock_lint once with that flag, so a push that adds a test file with a timing bet is blocked and hits in existing files only warn. Tests: `scripts/test_clock_lint_timing.py`.
