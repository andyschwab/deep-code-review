### Added
- Agentic-CEO: `token_report.py` (and so `/cost-retro`) gains a live 5-hour window view, `burn_blocks.active` in `--json` and an `Active window` text line, when the clock sits inside the newest window: minutes left, burn per minute so far, the projected total at the reset and, with the new `--limit N` (your own weighted-token budget per window, never guessed), percent used and minutes to reach it. When the pace passes the limit, or with no limit reaches 2x the median of earlier windows, a `Lever:` line names the fix from measured fields: `/compact` or `/clear` plus a handoff when main context over the auto-compact window drives it, trim the lane that drives it, else pause new lanes and use a cheaper tier until the reset. This matches the active-block remaining-time, burn-rate and projection view of ccusage `blocks` (public docs read 2026-10-22) and adds the concrete lever; usage, timestamp and model fields only, never message text. The projection and lever wait until 15 minutes of the window have passed (earlier it prints "too early to project"); `--limit` must be a finite number above 0 and prints a note when no live window exists.
