### Added
- Hand-back hygiene: the SubagentStop hook (`handback_cap.py`) now also warns when a lane hands back from a linked worktree with uncommitted or untracked paths (`git status --porcelain`, gitignored files excluded; linked worktrees only, told apart by `git-dir` differing from `git-common-dir`, and read-only reviewer/investigator/audit/explore agent types are skipped). It follows the existing `background_guard` switch: `warn` (default) adds the finding to the single `systemMessage`, `block` exits 2 (released after the push-hold window), `off` skips it; the main checkout is never reported and a git failure fails open with `COULD_NOT_CHECK`. A leaked-listener check is not added: `reap_own.sh --report` returns `orphans=COULD_NOT_CHECK` in the sandbox, so no usable primitive exists there. Tests: `scripts/test_handback_dirty.py` (registered in `scripts/ci-tests.d/handback-dirty.sh`).
