### Added
- `token_report.py --fix-plan` prints a minimal JSON settings patch for the fired levers that map to a key: `promptCacheTtl` `1h`, `autoCompactWindow` (the computed window), `bashOutputMaxChars` (the documented 10000 starting value), and env `LANE_TOOL_CAP` set to the lane p90 when that lowers the cap. Keys already set are skipped, and the subagent-model rule is never patched because it names no value. `--apply PATH` merges the patch into the symlink-resolved PATH: it refuses unreadable or invalid JSON and I/O errors (exit 2), writes `PATH.bak` only if absent with PATH's mode, replaces the file atomically, adds only absent keys, creates a missing PATH in an existing directory (mode 0600), and a second run prints `nothing to apply`. Under `--advise`, a lever whose key is already set no longer shows in the `Lever:` lines or `Top levers`, and unreadable settings print a note. Tests: `scripts/test_token_apply.py`.
