### Fixed
- The size ratchet (`ci-gates.sh size-ratchet`) now measures a raise from the larger of the file's real size at the base ref and its `size-budgets.tsv` row there. Lanes no longer commit rows, so after any landed PR grew a budgeted file the base rows were stale and every later PR failed with a raise it did not make. On a landed tree the row equals the size (or is a hand-kept budget above it), so nothing changes there. A `size-budget-raise:` marker names that larger base value as its old value. Five new cases in `scripts/test-ci-gates.sh` cover an untouched file with a stale row, real growth, a marker on the real size, a marker built on the stale row, and a hand-kept row above the size.
