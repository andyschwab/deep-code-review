### Fixed
- `mutation_changed.py` no longer reports a false "OK" when a test never executes the changed code. mutmut 3.x leaves those mutants "not checked", and 1.581.0 treated them as clean. They are now reported as `NOT_COVERED <file>:<line>: changed code no test executes`, and count as findings under `--strict`. On the Python half of the vacuous-test corpus (10 vacuous, 10 genuine tests), weak tests caught rose from 5/10 to 10/10, a post-hoc result measured on the same set that exposed the bug. False positives: 1/10 equivalent mutants; 4 more genuine tests are thin enough that mutants of their code really survive.
