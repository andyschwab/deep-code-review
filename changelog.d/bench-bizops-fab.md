### Added
- Benchmark: `scripts/bizops_fab_bench.py` tests whether a minimal edit to the business-ops skill (never state a number or citation the user did not supply or you did not fetch) lowers fabrication on fresh bait prompts without losing usefulness, with deterministic predicates, control prompts that check arithmetic on user-supplied numbers, and a preregistered keep rule. Result on 36 held-out fabrication prompts and 8 controls: strict fabrication 0.58 current vs 0.47 edited, paired difference +0.11 with 95% CI [-0.03, 0.25], so a tie; the edit is not kept and the skill is unchanged. Preregistration, raw outputs and per-case token counts are in `docs/bench/bizops-fab-1019/`. Tests: `scripts/test_bizops_fab_bench.py` (registered in `scripts/ci-tests.d/bizops-fab-bench.sh`).
