### Added
- deep-code-review: `review_checks.sh` reads a precomputed semgrep result. With `REVIEW_PRECOMPUTED=<dir>` it starts no semgrep process and reads `<dir>/semgrep.json`, an envelope (`envelope` 1, `scanner`, `tool` semgrep, `status` ran|failed|skipped, `exit`, `version`, `rules`, `report` as a `semgrep --json` string, `reason`). `ran` with exit 0 goes through the existing `sjson semgrep` parser (changed files only, rule ids as given) and is reported as `semgrep (precomputed)` under analyzers ran, `precomputed: semgrep` in the closing line and `precomputed` in `review-checks-last.json`; `failed`, `skipped`, a non-zero exit, or a missing or malformed envelope goes through `skip()` into NOT RUN with the reason and a not-checked row, never clean, and never falls back to a live run. `machine-report.md` gains `ground_truth.analyzers`, one row per wired analyzer read off those summary lines. Without the env var, behaviour is unchanged. Test: `scripts/test-review-checks-precomputed.sh`.
