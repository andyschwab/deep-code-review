### Added
- Agentic-CEO: `token_report.py` answers "where does my money go" across projects, months, models and lane types. `--rollup auto` prices the current directory's project (the `~/.claude/projects/<encoded cwd>` dir; an error when there is none), and `--rollup` on the `~/.claude/projects` parent prices every project under it, with one requestId dedupe across all of them. `--by month` adds calendar-month buckets beside day and week (adjacent for the delta, including across a year boundary). `--group project|agent|model` ranks spend by project, lane type (`agentType`; the main sessions are `main`) or model, each row with its share of priced spend. Cache hit % (cache read / (input + 5m and 1h cache writes + cache read)) appears in the text report's MAIN and SUBAGENTS lines and in every rollup, bucket and group row, `n/a` when there are no prompt tokens. A group, bucket or session holding an unpriced model stays `UNPRICED` (or `$X + UNPRICED (model)`), never $0. Reads usage, timestamps, model ids and the lane `agentType`; no message text or meta description reaches the output. `commands/cost-retro.md` step 2 and `docs/token-cost-tips.md` point at it. Tests: `scripts/test_spend_rollup_groups.py` (registered in `scripts/ci-tests.d/spend-rollup-groups.sh`), hand-computed on fake transcripts, and `scripts/test_spend_rollup_nits.py` (an unreadable project dir is skipped, `--rollup auto` without a project errors, the nudge watchdog keeps the advise line).
