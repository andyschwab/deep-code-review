### Added
- Operating layer: `landing_watchdog.py` now also counts open non-draft PRs in the same throttled `gh pr list` call and, when the count exceeds the new policy key `wip_cap` (integer >= 0, default 0 = off; opt-in until a cap is benchmarked), adds a second warn-only line: "WIP: N open PRs > cap M. Drain (review, land) before spawning." The `check` CLI exits 1 for either line. The coordinator loop template gains a WIP-first step 0, passes `--live-lanes` and `--max-lanes` to `host_probe.py` so the lane cap fires, and ends a wake as idle only after `lane_liveness.py` reports no ALIVE or QUIET lane (otherwise it says "draining"). Tests: `scripts/test_wip_cap.py` (registered in `scripts/ci-tests.d/wip-cap.sh`) and `scripts/test-loop-templates.sh`.
