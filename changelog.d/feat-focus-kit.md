### Added
- `scripts/focus_kit.py` in `agentic-delivery`: a stdlib focus kit that keeps agents on task across long sessions, compactions and new sessions. `handoff set|add SECTION TEXT` changes one section of `.claude/handoff.md` in place (created from the new `templates/handoff.md`: Goal, Stage, Next 3 steps, In flight, Blockers / owner asks, Decisions), leaves every other section byte-identical, and refuses a result over 1900 bytes so `handoff_inject.py` never truncates it. `memory-lint [DIR]` reports memory hygiene and never writes or deletes: index budget (150 lines, 20KB) and line length (150 characters), one fact per file (3KB, 3 headings), duplicate links, duplicate titles and near-duplicate files, orphan and dangling index entries, stale dates (default 30 days), and paths or script flags that no longer exist; it also checks the always-loaded `CLAUDE.md` and `AGENTS.md`. `docs-index [--check]` writes `docs/INDEX.md`, one "read this when" row per project doc, cut by the same helpers as `scripts/skill_index.py`; `--check` is the CI gate. `measure` prints the bytes an agent reads to recover state.
- `references/focus-kit.md`: when to update the handoff (each milestone, before a context-heavy step, before handback), the memory-hygiene rules, the docs-map convention and how a new session resumes. It is routed from `agentic-delivery/SKILL.md` and from the `agentic-ceo` conductor skill, and it keeps the owner's asks in the task ledger instead of copying them into a second list.
- `docs/INDEX.md` for this repository (`docs/bench` left out), linked from `CLAUDE.md`, rebuilt by `land-release.sh --regen` (lanes do not commit it; CI rebuilds an unlanded tree) and checked in CI. `.claude/handoff*.md` is gitignored. The Claude Code memory and context-window facts the kit relies on are logged in `docs/standards-index.md` (fetched 2026-10-16).
- Measured on this repository on 2026-10-17 with `focus_kit.py measure --exclude bench`: reading `CLAUDE.md`, `AGENTS.md` and every doc is 621,293 bytes (258,347 without the 362,946-byte standards index); `docs/INDEX.md` is 2,957 bytes and the injected handoff is capped at 1,900 bytes, so recovering state reads at most 4,857 bytes. `CLAUDE.md` and `AGENTS.md` (7,028 bytes) stay auto-loaded either way. The baseline is an upper bound: it counts reading everything, which an agent would not do.
