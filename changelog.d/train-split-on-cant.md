### Added
- Agentic-delivery: `train_land.sh` no longer stalls the queue when a red train has no attributable culprit. Where it used to exit `CANT` (exit 3) and land nothing (`no culprit pinned` or `real failure(s) not pinned`), it now splits the remaining PRs into halves, re-runs the full gate on each half stacked on the fresh base, lands a half only when its own gate is green, and recurses on a red half up to `TRAIN_SPLIT_DEPTH` (default 2; `0` restores the old behavior, a non-number disables splitting with a warning). Each later half redoes the push-lock and lease waits and lands only while the base is still the one it was gated on. A leaf (a single PR or the depth floor) keeps the CANT and FLAKY semantics: it lands nothing. Only a CANT leaf continues the split; exit 2, 4 and 126+ abort it. The run always prints `SPLIT done: landed #...; CANT (not landed) #...; gates=<n>` (landed is what `land_train.sh` merged), and exits 0 only when every PR landed, else 3. The flake-on-base CANT never splits. Documented in `references/red-gate-triage.md`. Tests: `scripts/test-train-split.sh` (registered in `scripts/test-ci-gates.sh`); `scripts/test-peer-pains-2.sh` now pins `TRAIN_SPLIT_DEPTH=0` for its plain-CANT cases.

### Fixed
- Agentic-delivery: the exclusive heavy lease is now renewed from `train_land.sh`'s gate subshell: `perun_policy.py` heavy-exclusive commands honor `PERUN_HOLDER_PID`, which `train_land.sh` sets to its own pid on the renew call only (the renew previously credited the subshell and did nothing). The override is honored only for a positive pid that is the caller's parent or grandparent; anything else (0, -1, text, a foreign pid) falls back to the caller, so it can never release, renew or take another process's lease, and `_alive` now rejects pid <= 0.
