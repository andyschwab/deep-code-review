### Added
- Agentic-CEO: new `scripts/context_audit.py`, a read-only audit of the context that loads on every turn. It reports raw bytes, approximate tokens (bytes/4) and percent of the total for each instruction file (the same candidates `token_report.py --project` prices: `CLAUDE.md`, `AGENTS.md`, `.claude/CLAUDE.md`, the user-level `CLAUDE.md` and the project's `MEMORY.md`), each `MEMORY.md` under `--memory-dir` and each installed skill description (`--skills-dir`, defaults `./.claude/skills` and the user config dir's skills, `$CLAUDE_CONFIG_DIR/skills` else `~/.claude/skills`), then names one concrete cut per top offender: shorten MEMORY.md index lines over 200 characters, move a CLAUDE.md section over 4000 bytes to an on-demand reference, trim a skill description over 300 characters, and de-duplicate lines repeated across files. A file reached twice (repeat or symlink) counts once; a directory given as a path, a file given as `--memory-dir` or `--skills-dir`, or an unreadable file, exits 2; a skill row counts its description bytes only. `token_report.py` now exposes the shared `instruction_candidates()` and `est_tokens()` helpers that `startup_files` and the audit both use. Tests: `scripts/test_context_audit.py` (registered in `scripts/ci-tests.d/context-audit.sh`).
