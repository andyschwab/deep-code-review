### Added
- Operating layer: `landing_watchdog.py` now also warns on `PreToolUse` for `Agent` or `Task`, so autonomous runs that spawn lanes without ever receiving a user prompt still see "Landing stalled: ..." before starting more work. Main session only (an input with `agent_id` stays silent), warn-only (never denies), and it reuses the existing cached verdict and 15-minute throttle with no new network path. `UserPromptSubmit` behaviour, `off` mode and fail-open are unchanged. Wired under the existing `Agent|Task` PreToolUse matcher in the operating-layer settings template. Tests: `scripts/test_landing_watchdog.py` (run in CI).
