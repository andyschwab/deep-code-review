### Added
- Benchmark: `docs/bench/token-levers/` is a reproducible showcase of what `token_report.py` tells a user, next to six peer tools (caveman, ponytail, RTK, context-mode, Headroom, ccusage). A synthetic transcript fixture (no real content, regenerated byte for byte by `gen.py`) and `run.sh` assert the four levers, their ranking and amounts: pin main cache to 1h (at most 35.3% of session input-eq), lower the lane tool-call cap (13.1%), auto-compact at 200K (6.0%), orchestrator tier (unpriced). The README tabulates what each peer's public README says it reports, with the peers' own numbers, and lists where peers beat Perun (per-output compression, output voice, time-bucketed spend views, applying fixes). Peer pages are logged with the fetch date in `docs/standards-index.md`. Tests: `scripts/ci-tests.d/token-levers.sh`.
