Bench-integrity gate: scripts/bench_check.py fails new bench dirs with tune/held scenario id collisions, byte-identical outputs reused from another bench, a missing or late preregistration ledger event, a PREREGISTERED doc naming a missing hash file, or heavy 10-word shingle overlap with earlier benches

Recurring reviewer findings on preregistered benches (id collisions behind skip-if-exists output reuse, no ledger.jsonl, a frozen hash file rewritten after the ledger hash, a loosened overlap check, a prereg doc naming a nonexistent hash file) are now checked mechanically. `python3 scripts/bench_check.py DIR...` checks the named dirs; `--changed` checks only docs/bench dirs absent from origin/main, so legacy benches without ledgers are not gated. The ledger needs a `{"event": "preregistered", "sha256": <prefix of sha256(SHA256-frozen.txt), at least 12 hex>}` line before the first generation line. Template phrases go in DIR/overlap-allow.txt and deliberately shared outputs in DIR/reuse-allow.txt. The offline test is scripts/test_bench_check.py, registered in scripts/ci-tests.d/bench-check.sh. The checks are described once, in the script's docstring.
