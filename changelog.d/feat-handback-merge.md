### Added
- Delivery: `handback.py --repo OWNER/NAME --merge-pr N` closes the lane last mile: after the gates and the exact-SHA required-checks verdict are GREEN and `review_gate.py` finds an independent review receipt for that head, it prints `gh pr merge N --merge --match-head-commit SHA` (a dry run), and `--apply` runs it (it needs a 40-hex `--sha`, readable required-check names and a PR that targets `--base` at exactly that SHA; a failed merge is `handback RED: merge`, an unverified or red check never reaches it). With `--tracker-issue`, the HANDOFF post comes after the merge, so a refused merge never posts; `PERUN_GITHUB_ACTIONS` overrides the policy's skip-ci choice. It also prints a branch-prune command next to the teardown commands, and never runs either, so worktree removal and branch deletion stay an owner action.
