### Fixed
- Auto-update no longer skips with "no readable install marker" on older installs that have `.claude/.dcr-install-flags` but no `.claude/.perun-install.json`. `perun_auto_update.py` now treats such a repo as an install: the version comes from the installed `deep-code-review` `SKILL.md` frontmatter and the remote is the canonical public repo. Merge/rebase/train locks and uncommitted-change skips still apply; hash-drift cannot be checked because an old install recorded no hashes (install.sh backs up the skill dirs it replaces). The update writes the real marker, so this is one-time.
- `install.sh` now records the canonical public repo as the marker `remote` when `PERUN_REMOTE` is unset and the install source has no git origin (tarball or plugin copy), so the marker always carries a remote for auto-update.
