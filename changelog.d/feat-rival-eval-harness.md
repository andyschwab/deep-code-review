### Added
- `scripts/rival_eval.py` is a standing harness that scores every skill under `.claude/skills/` against its strongest public rival, so superiority is a number (win rate, bootstrap 95% CI, cost) rather than a hand-built bench. Each skill has a fixture under `scripts/eval-fixtures/rival/<skill>/` with a frozen held-out set (n of at least 10, its sha256 pinned in `rival.json`) and a tune set; a held-out run fails closed if the set (or a patch file it references) changed, overlaps the tune set or is too small, and a tune run never prints a verdict. Rivals reuse the texts already committed under `docs/bench/`; the five rivals that were never committed (positioning, contribution, business-ops, agentic-ceo, agentic-delivery) are fetched once from their public URL at run time and cached outside the repo. New scenario sets were written for agentic-ceo (session-start decisions) and agentic-delivery (tickets), plus positioning, contribution and business-ops; deep-code-review reuses the public review corpus under `scripts/eval-fixtures/bench/train`.
- Both arms answer with no tools. A rubric-free blind pairwise judge (DeepSeek-V4-Flash on the PCSS endpoint) sees every pair in both orders; a scenario is a win or loss only when both orders agree and is otherwise a tie (0.5). Each judge's slot-1 rate (share of decisive picks that chose Response 1) is reported as a health metric, and a judge outside 0.4-0.6 is dropped for that skill in favor of GLM-5.2; when both are biased the skill gets no verdict. The generator (default Qwen3.5-397B-A17B on PCSS, $0) is never a judge. `--gen claude` is opt-in: it makes one probe call, stops when plan-quota utilization reaches 0.8, and is capped at $0.50 per skill run and a total cap, counts in-flight reserves against the cap, and fails closed when no utilization reading comes back. A judge with no decisive verdicts counts as unhealthy, verdict caches are keyed on the scenario, the rubric and the judge, and `write heldout` refuses to overwrite a frozen set without `--force`. `PCSS_KEY` comes from the environment or a repo-root `.env` and is never printed.
- `--changed [BASE]` scores only the skills a diff touches; `scripts/rival-eval-premerge.sh` is the local pre-merge hook point (for example `DCR_PREPUSH_CMD="bash scripts/rival-eval-premerge.sh"`). It needs a local key, so CI never runs it.
- `scripts/test_rival_eval.py` (registered in `scripts/ci-tests.d/rival-eval.sh`) covers the scorer, the bootstrap CI math, split hygiene on every committed fixture and on broken ones, `--changed`, the quota and cap gates, and key redaction, with the model calls replaced by fakes.
- `docs/bench/rival-eval-baseline-1017/` holds the first held-out baseline (10 scenarios per skill, $0 spend): no skill passes, and three skills have no verdict because neither judge was position-unbiased on them.
