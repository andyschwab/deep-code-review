### Changed
- Token optimization: `deep-code-review/SKILL.md` is now a slim fast path (2.8 KB, down from 22 KB) for a small DIFF of at most 300 changed lines with no blast-radius flag: read every hunk, ask what input breaks each changed line, keep a finding only when a plausible input fails, at most 8 findings (matching compact mode), reported as the usual severity-ranked `file:line` list. The fast path also says to verify each finding by re-reading and tracing, to report only at confidence 80 or more, and to name the pinning test for every guarantee-bearing comment. Everything else (FILE, FULL, a larger or flagged DIFF, or anything touching auth, crypto, payments, data deletion or another high-stakes gate) starts by reading the new `references/full-map.md`, which holds the previous `SKILL.md` body (including the INDEX.md skip text and the Observability and Documentation domain rows) (scope modes, principles, archetype load map, domain map, severity rubric, definition of done) behind a "Read this when" line. The `routing` gate now accepts a reference routed through `full-map.md` but still requires `full-map.md` itself to be named in `SKILL.md`, and also checks that every route inside `full-map.md` resolves. The `mustload` gate reads its load-map and phase tables from `full-map.md` and counts that file (not the slim `SKILL.md`, which `routing --max-bytes` and the new test bound separately) in the Phase 0-2 floor, so both floor pins re-pin down by 14 tokens (22796 and 30772). `scripts/floor-anchors.tsv` and `scripts/hidden_test_bench.py` follow the moved sections, as do `scripts/review_load_bytes.py` (quick path is now `SKILL.md` alone; the full path reads the map and still skips `INDEX.md` when the map says a routing match does) and the tests that pinned old `SKILL.md` text. `size-budgets.tsv` gets a `full-map.md` row and a lower `SKILL.md` row. Tests: `scripts/test_slim_skill_fast_path.py`.
