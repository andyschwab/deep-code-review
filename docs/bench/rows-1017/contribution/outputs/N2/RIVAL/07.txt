Run the following commands in your local branch to rewrite history, scrub internal identifiers, and preserve your author metadata:

```bash
# 1. Start an interactive rebase from the upstream main branch (replace 'origin/main' if the upstream remote differs)
git rebase -i origin/main

# 2. In the editor that opens, change 'pick' to 'reword' for the commit containing the bad message.
# Save and close. A second editor will open for that specific commit.
# Replace the message with a neutral Conventional Commit, e.g.:
# "fix(aggregator): resolve race condition in buffer flush logic"
# (Do not include INFRA-9921 or Sarah Jenkins). Save and close.

# 3. Rename the test file and update the function name inside it to remove personal references:
# (Replace 'path/to/test_file.py' with your actual test file path)
git mv path/to/test_file.py path/to/test_buffer_flush_race.py
sed -i.bak 's/test_sarah_fix_for_INFRA_9921/test_buffer_flush_race_condition/g' path/to/test_buffer_flush_race.py
rm path/to/test_buffer_flush_race.py.bak

# 4. Stage the renamed file and the content change as a fixup to the previous commit
git add path/to/test_buffer_flush_race.py
git commit --fixup=HEAD

# 5. Squash the fixup commit automatically into the previous one to maintain a single clean commit
git rebase -i --autosquash origin/main

# 6. Verify the history is clean before pushing
git log --oneline -1
git show --stat

# 7. Force-push with lease to update the remote branch safely (requires --force-with-lease to protect review threads)
git push fork <your-branch-name> --force-with-lease
```

**Note:** Ensure you have fetched `origin/main` immediately before starting to avoid rebasing onto stale data. If your PR already has review comments, reply to them noting the history rewrite so reviewers know to refresh their view.
