## Summary
Fixes a null-pointer dereference in `Acme ImageLib` when loading corrupted PNG files by adding a null check before pointer dereference. This prevents crashes on malformed input, addressing a critical stability issue.

## What
- **File:** `src/png_loader.c` (or equivalent path)
- **Change:** Added `if (ptr == NULL) return ERROR_CODE;` before the dereference site at line `N`.
- **Scope:** Strictly limited to the null-check; no refactoring or style changes included.

## Why
Loading corrupted PNGs currently causes an immediate crash (SIGSEGV) due to unchecked pointer return from the header parser. While valid PNGs are unaffected, robust libraries must gracefully handle malformed input rather than terminating. This fix ensures the library returns an error code instead of crashing.

## Backward Compatibility
Fully backward compatible. Valid PNG loading behavior is unchanged. The only difference is that previously crashing inputs now return a standard error code.

## Security Considerations
This fix mitigates a potential Denial of Service (DoS) vector where an attacker could supply a malformed PNG to crash services relying on ImageLib.
