### Demo Video Recording Checklist: Offline Mode Crash Fix

**Pre-Recording Setup Verification**
*   [ ] Confirm the emulator instance is a fresh, factory-reset image with no user accounts, saved trails, or personal data.
*   [ ] Verify the app build includes the specific state management fix for network transitions.
*   [ ] Ensure screen recording software is active and capturing the full emulator window clearly.

**Execution Sequence**
1.  **Initial State Display**: Launch the app and navigate to the main dashboard. Explicitly show the "Settings" or "Profile" screen is empty to prove no user data exists.
2.  **Baseline Connectivity**: Show the device status bar indicating active Wi-Fi/Data connectivity. Open the app's internal network status indicator (if available) to show "Online."
3.  **Rapid Toggle Stress Test (Phase 1)**:
    *   Enable "Airplane Mode" on the emulator.
    *   Wait 2 seconds.
    *   Disable "Airplane Mode."
    *   Immediately repeat this cycle 5 times in quick succession.
    *   *Narration Point*: State aloud: "Performing rapid online/offline transitions on an empty data state."
4.  **Functional Verification During Transition**: While toggling, attempt to open the "Saved Trails" list and the "Map View." Show that the app remains responsive and does not freeze or crash during the state flips.
5.  **Rapid Toggle Stress Test (Phase 2 - Edge Case)**:
    *   With the app open on the Map View, toggle Airplane Mode 3 times rapidly.
    *   Attempt to click a map pin or UI element immediately after the final toggle.
6.  **Stability Confirmation**: Leave the app running in the final state (either online or offline) for 15 seconds. Navigate between two different internal tabs to prove the state manager held integrity.
7.  **Final State Display**: Return to the main dashboard. Re-verify that no new data has been generated or cached that resembles personal user information.

**Post-Recording Validation**
*   [ ] Review the footage to ensure no accidental pop-ups, notifications, or background apps containing personal info are visible.
*   [ ] Confirm the video clearly shows the app surviving the rapid toggles without closing or throwing a fatal error dialog.

**Note**: This checklist strictly isolates the state management logic verification from any data-dependent scenarios to satisfy your privacy constraints. Ensure the final video file is scrubbed of any emulator device IDs before submission.
