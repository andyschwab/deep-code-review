Here are the precise git commands to rewrite your local history, removing the internal identifiers and personal names while preserving the technical fix and your author metadata.

**1. Start an interactive rebase**
Replace `~N` with the number of commits back to the one you want to fix (e.g., `~1` for the most recent, `~3` for the last three).
```bash
git rebase -i HEAD~N
```

**2. Mark commits for editing**
In the editor that opens, change the word `pick` to `edit` (or `e`) next to every commit containing the sensitive data. Save and close the file. Git will stop at the first marked commit.

**3. Rewrite the commit message**
At the first stop, run:
```bash
git commit --amend
```
In the editor, delete "INFRA-9921" and "Sarah Jenkins." Rewrite the message to describe the race condition fix neutrally (e.g., "Fix race condition in buffer flush logic"). Save and close.

**4. Rename the test function**
Edit the test file to rename the function:
```bash
# Open your test file in your editor
# Change: def test_sarah_fix_for_INFRA_9921():
# To:     def test_buffer_flush_race_condition():
```
Stage the change and amend the commit again to include this filename change:
```bash
git add <path_to_test_file>
git commit --amend --no-edit
```

**5. Continue the rebase**
Resume the process for the next marked commit (or finish if this was the last one):
```bash
git rebase --continue
```
Repeat steps 3–5 for each commit until the rebase completes.

**6. Verify the cleanup**
Check the history to ensure no identifiers remain:
```bash
git log --oneline
git grep "INFRA-9921"
git grep "Sarah Jenkins"
```
If `git grep` returns nothing, the sensitive data is removed from the history.

**7. Force push (if previously pushed)**
If you already pushed the dirty commits to a remote branch, you must force push the cleaned history:
```bash
git push --force-with-lease origin <branch-name>
```

**Note:** Your contributor license agreement signature is tied to your Git user email/name configuration, not the commit message text, so your legal attribution remains intact. Never use these commands on shared public branches without coordinating with collaborators, as rewriting history changes commit hashes.
