### UI State & Error Simulation Checklist for Stellar Desktop Report Export

**Objective:** Provide your colleague with this exact list to capture before-and-after screenshots and verify error handling on a Windows environment.

#### 1. UI States to Capture (Screenshots)
*Request your colleague to capture these specific moments in the workflow:*

**A. Pre-Feature State (Baseline)**
*   **View:** Main Dashboard → "Export Reports" button (current state).
*   **Action:** Click "Export Reports."
*   **Capture:** The existing file save dialog (or lack thereof if currently hardcoded).
*   **Label:** `01_baseline_export_dialog.png`

**B. Post-Feature State (Happy Path)**
*   **View:** Main Dashboard → "Export Reports" button (new state).
*   **Action:** Click "Export Reports."
*   **Capture:** The **new** custom file picker dialog appearing, specifically showing the "Isolated Data Directory" path pre-filled or selectable.
*   **Label:** `02_new_isolated_picker_open.png`
*   **Action:** Navigate to a custom folder (e.g., `D:\StellarExports\Q3`) and select it.
*   **Capture:** The dialog confirming the selection and the path displayed in the UI after selection.
*   **Label:** `03_custom_path_selected.png`
*   **Action:** Complete the export.
*   **Capture:** Success toast/notification and the resulting file in the target directory (Windows Explorer view side-by-side if possible).
*   **Label:** `04_export_success_verification.png`

**C. Post-Feature State (Empty/Default State)**
*   **Action:** Open the picker without any prior configuration.
*   **Capture:** The dialog showing the default isolated directory path (e.g., `%APPDATA%\Stellar\IsolatedExports`).
*   **Label:** `05_default_isolated_path.png`

#### 2. Error Conditions to Simulate (Permission Errors)
*Request your colleague to force these specific failure modes and capture the resulting error UI:*

**A. Read-Only Folder Simulation**
*   **Setup:** Create a folder (e.g., `C:\StellarTest\ReadOnly`). Right-click → Properties → Check "Read-only" → Apply.
*   **Action:** Attempt to export a report to this specific folder using the new dialog.
*   **Capture:** The specific error modal/toast that appears. Ensure the error message explicitly mentions "permission" or "read-only."
*   **Label:** `06_error_readonly_folder.png`

**B. System Protected Directory Simulation**
*   **Setup:** Attempt to export directly to a protected system folder (e.g., `C:\Program Files\Stellar` or `C:\Windows`).
*   **Action:** Select this directory in the new file picker and confirm export.
*   **Capture:** The OS-level denial (if intercepted by Windows) OR the application-level error handling if the app catches the OS exception first.
*   **Label:** `07_error_system_protected_dir.png`

**C. Network Drive Disconnection (Edge Case)**
*   **Setup:** Map a network drive, select it in the picker, then disconnect the network drive *before* clicking "Save."
*   **Action:** Click "Save."
*   **Capture:** The error state indicating the path is unreachable.
*   **Label:** `08_error_network_unreachable.png`
