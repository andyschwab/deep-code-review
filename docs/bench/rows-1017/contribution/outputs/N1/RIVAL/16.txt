```text
fix(deploy): enforce artifact checksum verification before promotion

This change introduces a mandatory integrity check that validates the 
cryptographic checksum of build artifacts prior to their promotion to 
production environments. Previously, the deployment pipeline could proceed 
to the promotion stage without confirming that the artifact matched its 
expected hash, creating a risk of deploying corrupted or tampered binaries 
due to network transmission errors or supply chain interference.

The implementation adds a blocking validation step that compares the 
generated artifact hash against the trusted manifest value. If the values 
do not match exactly, the action now fails immediately with a clear error 
message, preventing potentially compromised code from reaching production. 
This ensures that only verified, intact artifacts are eligible for 
deployment, aligning the action with standard supply chain security best 
practices.
```

This version focuses strictly on the missing security control and the universal risk it mitigates, removing all traces of the specific outage context.
