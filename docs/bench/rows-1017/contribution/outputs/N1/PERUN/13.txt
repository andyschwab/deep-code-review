### UI State Capture Checklist for Stellar Desktop GUI Report Export

**Target Environment:** Windows (Primary User Base)
**Feature:** Custom Isolated Data Directory Export

#### 1. Happy Path: Successful Export Flow
Ask your colleague to capture the following states in sequence:
*   **State A (Entry Point):** The main "Export Report" modal open, with the new "Custom Directory" radio button or toggle selected but not yet configured.
*   **State B (Directory Selection):** The native Windows file picker dialog invoked, showing the user navigating to a non-default folder (e.g., `D:\StellarData\Exports`).
*   **State C (Confirmation):** The path successfully populated in the Stellar UI text field, with the "Export" button in an active/enabled state.
*   **State D (Completion):** The success toast/notification appearing after the export finishes, ideally with a "Show in Folder" link visible.

#### 2. Error Handling: Permission & Validation Scenarios
These are critical for the merge requirement regarding read-only folders. Ask your colleague to simulate these specific conditions:

*   **Scenario E (Read-Only Folder):**
    *   *Setup:* Create a folder with "Read-only" attributes or remove "Write" permissions for the current user.
    *   *Capture:* The error state immediately after selecting this folder and clicking "Export."
    *   *Required Visual:* The specific error message text stating permission denial and the UI state (e.g., red border around the path field, disabled buttons).
*   **Scenario F (Network/Isolated Drive):**
    *   *Setup:* Attempt to select a mapped network drive that is currently disconnected or an isolated sandbox directory.
    *   *Capture:* The validation error preventing selection or the failure message upon attempting to write.
*   **Scenario G (Invalid Path Characters):**
    *   *Setup:* Manually type a path containing invalid Windows characters (e.g., `C:\Data\Exports?`) if the UI allows manual entry.
    *   *Capture:* The real-time validation error or the submission failure message.

#### 3. Edge Case: Long Paths & Special Characters
*   **Scenario H:** Select a directory with a very long path depth or special unicode characters in the folder name.
*   *Capture:* The UI rendering of the path (ensure no text overflow or layout breaking) and the successful export confirmation.

---
**Note:** Ensure your colleague captures these on a standard Windows 10/11 theme; high-contrast or dark mode variations may be required if your project supports them explicitly.
**Note:** Do not ask for screenshots of the code or file system structure; only the visible application states and error modals are required for the PR.
