### Step-by-Step Command Sequence

1.  **Fetch the latest upstream changes** to ensure you are rebasing onto the current target branch:
    ```bash
    git fetch origin
    ```

2.  **Start an interactive rebase** onto the target branch (replace `main` with your specific target branch name):
    ```bash
    git rebase -i origin/main
    ```

3.  **Edit the commit list** in the editor that opens:
    *   Keep the first commit as `pick` if it contains the maintainer's requested logic changes.
    *   Change `pick` to `edit` (or `e`) for any commit that needs bot fixes (formatting, commit message style, changelog).
    *   Save and close the editor.

4.  **Apply fixes at each pause**:
    *   Git will stop at the first commit marked `edit`.
    *   Make the necessary code formatting changes or add the missing changelog entry to the working directory.
    *   Stage the changes: `git add <files>`.
    *   Amend the current commit to include these fixes:
        ```bash
        git commit --amend --no-edit
        ```
    *   If the bot complained about the **commit message** specifically, use:
        ```bash
        git commit --amend
        ```
        (Edit the message in the editor to satisfy the style guide, then save/close).
    *   Continue the rebase:
        ```bash
        git rebase --continue
        ```
    *   Repeat this process for every commit marked `edit`.

5.  **Verify the final history** once the rebase completes:
    ```bash
    git log --oneline
    ```
    Ensure the commit messages match the style guide and the changelog entry is present.

6.  **Force-push safely** to update the remote branch (this rewrites history, so `--force-with-lease` is safer than `--force`):
    ```bash
    git push --force-with-lease origin <your-branch-name>
    ```

### Notes
*   If conflicts occur during rebase, fix the files, `git add` them, and run `git rebase --continue`; do not run `git commit` manually during conflict resolution.
*   `--force-with-lease` ensures you do not overwrite changes if someone else pushed to your branch while you were working.
