**Testing Methodology:**
1.  **Segment:** Split the next 2,000 trial signups 50/50.
2.  **Control:** Show existing 3-tier + 15 add-ons.
3.  **Variant:** Show 3 Usage Bands (e.g., $499, $1,999, $9,500) with zero visible add-ons; include overage logic only in the contract, not the checkout UI.
4.  **Metric:** Primary = Trial-to-Paid Conversion %; Secondary = Day-30 ARPU.
5.  **Success Criteria:** Proceed if Conversion increases by >20% relative to control AND ARPU declines by <5%.
