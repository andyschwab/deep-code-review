**The Call**
Reject immediate recognition. Because you stated the implementation services are **not distinct** from the software license, GAAP (ASC 606) requires you to treat the license and implementation as a **single performance obligation**. You must amortize the total contract value ($325,000 per deal) ratably over the three-year term. Recognizing the $75,000 upfront is non-compliant and creates severe audit and fundraising risks.

**The Numbers**
*Formula:* Annual Recognized Revenue = (License Fee + Implementation Fee) / Contract Term (Years).
*Inputs:* License = $250,000; Implementation = $75,000; Term = 3 years.
*Assumption:* Contracts are identical and start immediately (ASSUMED).

*   **Proposed:** $225,000 total implementation revenue recognized ($75k × 3 deals).

*   *Note:* Inflating revenue does not increase cash or extend runway; it only alters the P&L top line. Investors in Series B diligence will adjust EBITDA and revenue multiples back to the compliant figure, potentially penalizing the misstatement.

**What Flips It, and the Trigger**
The single input that changes this call is **distinctness**.
*   *Trigger:* If you can prove the customer can benefit from the license *without* your implementation AND your implementation is not highly customized/integrated with the license (i.e., a third party could perform it), you may separate them.
*   *Your Constraint:* You explicitly stated the services are "not distinct." Under ASC 606, if the service is highly specialized and integrates the software, it is bundled.
*   *Rule of Thumb:* If the implementation modifies the core code or is essential for the software to function as promised, it is one obligation.
*   *Step this week:* If your implementation is truly generic (e.g., standard SSO setup), **consider** engaging counsel to draft a "distinctness memo" analyzing whether a third party could perform the setup. If not, proceed with amortization.
