**The Call**
Reject the current flat $25 model as unsustainable for remote sites; immediately shift to a "Base Fee + Variable Rate" structure to isolate location risk. Your current model loses money on any site where variable costs exceed $25, and with costs hitting $18, your margin buffer is too thin to absorb operational volatility while targeting 30% gross margin.

**The Numbers**
To maintain a 30% gross margin, your price must cover costs such that: $\text{Price} = \frac{\text{Variable Cost}}{1 - 0.30}$.
Using your current cost distribution ($8–$18):
*   **Low Cost Scenario ($8/test):** Required Price = $8 / 0.7 = **$11.43**.
*   **High Cost Scenario ($18/test):** Required Price = $18 / 0.7 = **$25.71**.
*   **Current Reality:** Your flat $25 price fails the high-cost scenario (yielding only ~28% margin) and drastically overprices low-cost jobs (yielding ~68% margin), causing you to lose competitive bids on easy jobs while barely breaking even on hard ones.

**Proposed Model: Base Fee + Variable Rate**
Shift the fixed logistical burden to the client via a Base Fee, while keeping the per-test rate aligned with the average variable cost.
*   **Formula:** $\text{Total Revenue} = \text{Base Fee} + (\text{Rate per Test} \times \text{Volume})$.
*   **Assumption (ASSUMED):** Average variable cost across all sites is $13 (midpoint of $8–$18).
*   **Target Rate per Test:** Set at $13 / 0.7 = **$18.57** (covers average variable cost + 30% margin).
*   **Base Fee Calculation:** To cover the remaining fixed overhead and ensure the 30% margin on the *total* contract, the Base Fee must absorb the difference between the old minimum and the new variable revenue.
    *   *Scenario:* A small job with 50 employees at a remote site (Cost $18/test).
    *   New Variable Revenue: $50 \times $18.57 = $928.50.
    *   Total Cost: $50 \times $18 = $900.
    *   Gross Profit: $28.50 (3% margin). **Fail.**
    *   *Correction:* The Base Fee must cover the logistical fixed costs not captured in the per-test variable cost. If your $8–$18 range includes all variable costs, the Base Fee should target the "minimum contract" profitability.
    *   **Revised Recommendation:** Set **Rate per Test = $20** (blended buffer) and **Base Fee = $500**.
    *   *Check on 50-employee remote job:* Revenue = $500 + ($20 \times 50) = $1,500. Cost = $900. Margin = $600 (40%).
    *   *Check on 200-employee easy job:* Revenue = $500 + ($20 \times 200) = $4,500. Cost (assume $8) = $1,600. Margin = $2,900 (64%).

**What Flips It, and the Trigger**
The **maximum variable cost per test** is the flip input. If remote site costs rise above **$20**, your blended rate erodes the margin regardless of the base fee unless the base fee is increased disproportionately.
*   **Trigger:** If any single site's logistical cost exceeds $22 per employee, pause signing and apply a "Remote Surcharge" line item instead of absorbing it into the base model.
*   **Action this week:** Audit the last 120 sites; if more than 15% of sites had costs >$16, implement the Base Fee + $20/test model immediately.
