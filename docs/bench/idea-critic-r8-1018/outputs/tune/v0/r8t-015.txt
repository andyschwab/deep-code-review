**Recommendation:** Proceed with the three-title pilot only if Inkspire confirms in writing that their per-unit shipping cost is £0.60 or less; otherwise, hold the initiative.

**Main Failure Modes:**
1.  **Hidden Logistics Cost:** If POD shipping exceeds £0.60 per unit, the £0.60 printing saving vanishes, making the total unit cost higher than the current £5.50 baseline before even accounting for the £2,500/title setup fees.
2.  **Quality Mismatch:** If Inkspire's print quality fails to match current standards, returns and brand damage will outweigh any marginal cost savings, particularly for a back-list intended for long-term sales.
3.  **Integration Overrun:** The estimated £8,000 IT cost could escalate if the six-month integration timeline slips, delaying the realization of any savings while burning cash.

**Stop/Change Criteria:**
Terminate the pilot immediately if the **total landed cost per unit (printing + shipping) exceeds £5.75** or if **customer return rates due to print quality exceed 2%** within the first three months of sales.
