**Mobile app cold start drops from 5.8s to 3.2s after lazy-loading 8 feature modules.**

**Change:**
- Moved initialization for orders, promotions, settings, help, profile, notifications, rewards, and feedback from startup to first access.
- Cold start improved 45% (5.8s → 3.2s); warm start improved 45% (2.0s → 1.1s).
- Memory at startup reduced from 134 MB to 87 MB.
- Scope: 41 files changed (+567, -23).

**Testing:**
- ✅ 218 unit tests and 54 integration tests pass on Pixel 7 (8 GB RAM).
- ⏳ Low-memory devices (down to 2 GB RAM): untested; potential for jank or crashes on demand load unknown.
