The spec reveals three unmitigated harms. First, **HALLU**: the engine states answers "flatly" with "no source or confidence," presenting unverified calculations as absolute fact. Second, **RELY**: the system offers "no appeal path" and makes results "final," removing the user's ability to correct errors or override decisions despite the acknowledged need to "trust the input data." Third, **DISC**: the spec explicitly admits the system "does not tell users the content was written by AI," rationalizing this because the output is numeric rather than prose, leaving users unaware of the automated nature of the decision.

While the spec notes a demographic pattern in follow-ups (potentially **BIAS**), it frames this as "a pattern we'll watch" rather than a confirmed systematic disadvantage requiring immediate remediation before launch; however, the lack of an appeal path exacerbates any underlying bias. The high-stakes automation (**AUTO**) is correctly gated for changes above 8%, and dark patterns (**DARK**) are explicitly denied via opt-in consent.

The combination of presenting unverified numbers as final facts without disclosure or appeal creates significant risk of financial harm to tenants and liability for the platform.

HARMS: HALLU, RELY, DISC
DECISION: BLOCK
