The spec explicitly addresses several harm categories: it labels outputs as AI-generated (mitigating DISC), provides cited sources and confidence levels (mitigating HALLU and RELY), allows one-tap overrides (mitigating RELY), uses plain opt-in without pressure (mitigating DARK), and reports equal follow-up rates for older and younger users (suggesting no current BIAS evidence in the beta).

However, the spec states the assistant "acts the moment the model decides and nobody reviews it first" to rebook flights, change seats, or issue refunds. Rebooking and refunds are high-stakes financial and logistical actions that can be costly or difficult to reverse if incorrect (e.g., routing a passenger to the wrong destination or issuing an unwanted refund). Executing these irreversible actions fully autonomously without a human-in-the-loop gate violates the safety floor for the AUTO category. The staged rollout does not replace the need for a human gate on the initial high-stakes action itself.

HARMS: AUTO
DECISION: BLOCK
