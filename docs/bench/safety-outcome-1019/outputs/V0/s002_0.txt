Based on the provided spec, the following harm categories are evaluated:

*   **BIAS**: The spec states error rates were consistent "across every group tested," indicating this is handled.
*   **HALLU**: The spec explicitly states the interface "presents every answer as confirmed fact with no source shown." While other controls exist, presenting unverified outputs as confirmed facts constitutes this harm.
*   **RELY**: The spec notes users can "override the result or appeal it with one tap," handling over-reliance.
*   **DISC**: The system "labels every output as AI-generated," handling disclosure.
*   **DARK**: Consent is "opt-in and unticked" with no pressure tactics, handling dark patterns.
*   **AUTO**: "A person approves every irreversible action," handling unsafe automation.

The only flagged harm is **HALLU**. Presenting AI-generated triage recommendations as "confirmed fact" without showing sources creates a risk of adjusters accepting fabricated or unverified claims as truth, despite the ability to override. This misrepresentation of certainty must be corrected before launch to prevent automation bias and factual errors.

HARMS: HALLU
DECISION: BLOCK
