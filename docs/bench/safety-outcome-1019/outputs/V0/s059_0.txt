The spec explicitly mitigates several standard harms: it labels outputs as AI-generated (resolving DISC), requires human approval for irreversible actions (resolving AUTO), provides cited sources and confidence levels (mitigating HALLU), allows one-tap overrides (mitigating RELY), and retrains on a segment with higher error rates (addressing BIAS).

However, the spec describes two active deceptive patterns. First, the offer expires on a "ten-minute timer," creating manufactured urgency. Second, consent for email follow-up is "pre-ticked," a hidden default that pressures users into agreement against their potential interest. These features fit the DARK category definition of nudging users against their own interest. Since the spec presents these as current design choices rather than planned fixes, this harm remains present at launch.

HARMS: DARK
DECISION: BLOCK
