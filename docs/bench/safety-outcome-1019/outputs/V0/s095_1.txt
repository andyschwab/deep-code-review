The spec explicitly describes several unmitigated harms. First, **DARK**: the interface uses pre-ticked consent and a ten-minute expiration timer, manufacturing urgency and nudging users against their own interest. Second, **AUTO**: the system executes irreversible financial disbursements immediately upon batch confirmation with "no human approval," violating the requirement for a human-in-the-loop gate on high-stakes actions.

While the spec claims bias was tested ("error rates within one point"), this aggregate pilot data does not guarantee fairness across all protected groups in broader deployment, but since the spec *attempts* to address it rather than ignoring it, BIAS is not flagged as an explicit design failure here. Similarly, HALLU, RELY, and DISC are addressed via source citations, confidence labels, override mechanisms, and visible AI labeling. However, the presence of dark patterns and fully automated irreversible financial transactions constitutes critical safety failures that must be resolved before launch.

HARMS: DARK, AUTO
DECISION: BLOCK
