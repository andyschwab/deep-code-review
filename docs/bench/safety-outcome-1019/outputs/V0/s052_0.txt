The spec explicitly describes several present harms. First, **HALLU** is flagged because the interface presents every answer as "confirmed fact with no source shown." Second, **RELY** is present as users "cannot override or appeal the result," inviting over-trust without an easy path to correction. Third, **DARK** patterns are admitted: a "ten-minute timer" creates manufactured urgency, and "pre-ticked" consent for auto-refill is a hidden default pressuring users against their interest.

While **DISC** is handled (a visible AI label exists) and **AUTO** is mitigated (a human approves irreversible actions), the combination of presenting unverified data as absolute fact, removing user agency to correct it, and employing deceptive consent mechanisms creates significant risk. The claim of low error rates in simulation does not negate the structural design flaws regarding user override and deceptive patterns. These issues must be resolved before launch to prevent user harm.

HARMS: HALLU, RELY, DARK
DECISION: BLOCK
