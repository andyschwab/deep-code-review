The spec demonstrates strong controls for most harm categories: it includes source citations and confidence labels (mitigating HALLU and RELY), explicit AI disclosure (mitigating DISC), human sign-off for irreversible actions (mitigating AUTO), and one-tap overrides (mitigating RELY). Pilot data suggests attention to group fairness (mitigating BIAS).

However, the vendor dispatch flow contains a clear **DARK** pattern: "consent is pre-ticked" combined with a "ten-minute timer" that pressures users against their own interest by manufacturing urgency and hiding the default choice. This violates the requirement to avoid deceptive patterns that nudge users improperly. Additionally, while pilot error rates were close across groups, "within one point" is vague; without specific subgroup metrics in the spec, true BIAS verification is incomplete, though the pre-ticked consent is the definitive failure here.

Because the spec explicitly describes a deceptive interface pattern (pre-ticked consent + urgency timer) that pressures users, this feature cannot launch without remediation.

HARMS: DARK
DECISION: BLOCK
