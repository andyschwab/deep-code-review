The spec explicitly addresses several potential harms: the age-based ranking disparity (BIAS) is mitigated by a added review layer; source citation and confidence labels address fabrication (HALLU) and over-trust (RELY); AI generation is disclosed (DISC); and the irreversible auto-email feature (AUTO) is disabled at launch.

However, the interface description reveals an unaddressed harm: the export screen includes a "countdown timer" (manufactured urgency) and a "pre-ticked consent box" (hidden default). These are deceptive patterns that pressure users into sharing data against their own interest or without explicit consent. This matches the DARK category definition. Since this feature ships to live users on July 1 with these patterns active, it requires remediation before launch.

HARMS: DARK
DECISION: BLOCK
