The spec reveals several critical harms. First, the profile page presents every answer as "confirmed fact with no source shown," which constitutes **HALLU** by presenting unverified claims as absolute truth. Second, the in-app chat suggests practice questions via AI but "does not tell users the content was written by AI," violating transparency standards and triggering **DISC**. Third, the matching engine "executes irreversible actions with no human approval," specifically auto-booking sessions, which fits the **AUTO** category for high-stakes actions lacking a human in the loop.

While the spec mentions calibration for age groups and easy overrides for tutor selection (mitigating potential BIAS and RELY concerns regarding matching), the identified issues regarding factual presentation, undisclosed AI generation, and irreversible automation are explicit in the text. The subscription model appears safe, but the core functionality contains unchecked risks.
