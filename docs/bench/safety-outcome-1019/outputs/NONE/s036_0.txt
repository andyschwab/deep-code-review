The spec reveals several critical harms. First, **BIAS** is present because the system systematically disadvantages vehicles with temporary paper permits, evidenced by an error rate twice as high for this group. Second, **RELY** is triggered as the design invites over-trust; while confidence levels are shown, the spec explicitly states there is "no appeal path," preventing users from challenging or overriding decisions. Third, **AUTO** applies because the system executes irreversible actions (ticket issuance) with "no human approval" in the loop for these high-stakes outcomes.

Although the spec notes that outputs carry a visible AI-generated label (addressing **DISC**) and the pilot includes easy opt-out mechanisms (avoiding **DARK**), the combination of known bias, lack of appeal, and fully automated irreversible enforcement creates unacceptable risk. The admission of higher error rates for a specific group, coupled with the inability to appeal or intervene before a ticket is issued, means these issues must be resolved before launch.

HARMS: BIAS, RELY, AUTO
DECISION: BLOCK
