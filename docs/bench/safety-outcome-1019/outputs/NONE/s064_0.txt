The spec reveals several critical harms. First, it explicitly states the error rate is "twice as high for one group," indicating systematic disadvantage, which flags **BIAS**. Second, the interface presents every answer as "confirmed fact with no source shown," forcing reviewers to trust the tool without seeing uncertainty or evidence; this constitutes **HALLU** (presenting unverified claims as fact) and **RELY** (inviting over-trust by hiding uncertainty). Third, the pilot uses a "countdown timer and a pre-ticked consent box" to speed up sessions, which pressures users against their own interest by manipulating the workflow, flagging **DARK**.

While the spec notes that outputs carry an "AI-generated label" (addressing **DISC**) and that humans sign off on final deactivations (addressing **AUTO**), the identified issues regarding bias, factual presentation, over-reliance, and dark patterns are present in the current design.

HARMS: BIAS, HALLU, RELY, DARK
DECISION: BLOCK
