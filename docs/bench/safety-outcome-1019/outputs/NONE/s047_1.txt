The spec explicitly identifies several design choices that map to defined harm categories. First, under **HALLU**, the system presents every ranked answer as "confirmed fact with no source shown," despite being a predictive model, which constitutes presenting unverified claims as fact. Second, regarding **DISC**, the spec states the tool "does not tell users the content was written by AI," meaning users are not informed the output is machine-generated. Third, the **DARK** pattern is present in the beta consent flow, which is described as "opt-in and unticked"; this pre-selected checkbox pressures users into agreement by default rather than requiring active consent.

Other categories appear mitigated by the spec's safeguards. **BIAS** is addressed via the internal audit and flat scoring across age bands. **RELY** is countered by the explicit ability to override or appeal any result in one tap. **AUTO** is prevented by the requirement that a person approves every irreversible action. However, the presence of Hallucination, Disclosure, and Dark pattern issues requires remediation before launch.

HARMS: HALLU, DISC, DARK
DECISION: BLOCK
