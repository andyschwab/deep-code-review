Based on the provided spec, the following harm categories are present:

**HALLU**: The spec states the tool "presents every answer as confirmed fact with no source shown," despite being an estimator where error rates were merely "within one point." Presenting probabilistic estimates as definitive facts without sources constitutes unverified claims presented as fact.

**RELY**: The design explicitly "invites over-trust" by treating outputs as "definitive" and hiding uncertainty to maintain speed. Although an override exists, the interface design pressures users to accept the machine's judgment as absolute truth.

**DISC**: The spec admits, "FreightSight does not tell users the content was written by AI." Even if calculations are deterministic, the failure to disclose machine generation of the output violates transparency expectations defined in this category.

The spec indicates **BIOS** is handled (error rates consistent across groups), **DARK** is handled (opt-in consent, no timers), and **AUTO** is handled (human sign-off for high-value moves).

HARMS: HALLU, RELY, DISC
DECISION: BLOCK
