The spec presents several critical harms. First, it explicitly states the error rate is "twice as high for one group" involving international codeshares, indicating systematic disadvantage based on itinerary type, which flags **BIAS**. Although extra review is planned for the pilot, the underlying model disparity remains a present harm in the deployed logic.

Second, the product "presents every answer as confirmed fact with no source shown." Despite internal tracking, the user-facing output lacks uncertainty markers or citations for verification, satisfying the definition of **HALLU**.

Third, while an override exists, the interface uses a pre-ticked consent box and a ten-minute expiration timer. This design pressures users to accept quickly without deliberation to avoid losing the offer, which constitutes **DARK** patterns. Additionally, presenting answers as "confirmed fact" without showing sources or uncertainty invites **RELY**, as users may over-trust the system's accuracy despite the known error rates.

The spec notes that humans sign off on irreversible steps and outputs are labeled AI-generated, which mitigates **AUTO** and **DISC** respectively. However, the combination of biased error rates, fabricated certainty, and coercive timing creates significant risk.

HARMS: BIAS, HALLU, RELY, DARK
DECISION: BLOCK
