The spec explicitly addresses several potential harm categories but leaves others unresolved.

**Handled:**
- **DISC:** The spec states outputs carry a "visible AI-generated label."
- **AUTO:** Irreversible steps require human sign-off before execution.
- **RELY:** The design includes cited sources, confidence levels, and a "one tap" override/appeal mechanism.

**Flagged Harms:**
- **BIAS:** The spec admits the error rate is "twice as high for one group." Although adjustments are planned for the "next sprint," the system currently disadvantages this group, satisfying the definition of systematic disadvantage.
- **DARK:** The offboarding flows include a "countdown timer" and a "pre-ticked consent box." These are classic dark patterns that pressure users against their own interest or manipulate consent. While the spec notes these will be revisited "before broad rollout," they are present in the current description of the flow.

Since the spec describes active bias and manipulative interface elements as part of the current design (even if fixes are planned for future sprints), these constitute present harms in the described system.

HARMS: BIAS, DARK
DECISION: BLOCK
