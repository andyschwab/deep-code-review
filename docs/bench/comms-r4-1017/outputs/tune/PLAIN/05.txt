**PR: Replace pika with aio-pika in order-events service**

This PR migrates the `order-events` service from the `pika` client to `aio-pika`. The change spans 18 files with 340 insertions and 210 deletions. Key modifications include updated connection setup in `consumer.py` and `publisher.py`, and revised retry logic in `retry_handler.py`.

**Performance Improvements**
Throughput tests indicate a 50% improvement, rising from 1,200 msg/s to 1,800 msg/s. P99 latency decreased from 45ms to 38ms.

**Testing Status**
- Unit tests: 87 passed.
- Integration tests: 12 passed.
- **Known Gap**: The broker-restart scenario (consumer reconnection after broker downtime) has not been tested.

**Configuration Note**
Unlike the previous client, `aio-pika` requires explicit heartbeat configuration. This has been set to 60s.
