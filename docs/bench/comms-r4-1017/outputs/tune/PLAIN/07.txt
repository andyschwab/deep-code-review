## Read Replica Integration for Reporting Dashboard

**Summary**
This PR redirects reporting dashboard queries from the primary database to a newly provisioned read replica to reduce primary load. A dedicated connection pool (size 10) has been implemented for replica connections.

**Performance Impact**
Latency improvements observed after deployment:
- **p95 Latency:** Reduced from 320ms to 110ms.
- **p99 Latency:** Reduced from 500ms to 210ms.

**Replica Lag & Data Consistency**
The replica currently exhibits an approximate lag of 2 seconds. This is acceptable for the dashboard's hourly data granularity. However, a known edge case exists: if replica lag exceeds 5 seconds, the dashboard's time-series query may return stale data. This scenario is rare (observed once in 100 test runs) and the associated test is currently marked as flaky.
