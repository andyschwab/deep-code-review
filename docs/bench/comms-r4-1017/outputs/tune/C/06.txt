Home and profile screens now lazy-load: cold startup drops from 3.2s to 2.1s (34% reduction) and APK size shrinks by 2.4MB.

**Changes**
- Implemented lazy-loading for home and profile screens using built-in dynamic imports; no new dependencies added.
- Modified 22 files (+450 insertions, -120 deletions).
- Reduced startup memory usage from 180MB to 150MB.

**Performance Results**
- **High-end/Mid-range:** Cold start (tap to first frame) improved from 3.2s to 2.1s.
- **Mid-range (Pixel 6a):** Improved from 4.1s to 2.8s.
- **Tested on:** 5 devices running Android 13 or 14.

**Known Issues**
- ⏳ **Race condition:** Navigating to the profile screen within 1s of launch causes a 200ms blank screen flash. This is logged and under investigation.
- ⏳ **Untested scenario:** Low-memory devices (e.g., Galaxy A10) were not tested due to hardware availability.
