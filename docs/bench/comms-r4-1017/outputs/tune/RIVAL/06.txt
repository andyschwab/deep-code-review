## Lazy-load home and profile screens

This PR updates the mobile app to lazy-load the home and profile screens using built-in dynamic imports. No new dependencies were added.

**Changes**
- 22 files changed (450 insertions, 120 deletions)
- APK size reduced by 2.4MB

**Performance improvements**
Startup time (cold start, tap to first frame):
- Average: 3.2s → 2.1s (34% reduction)
- Pixel 6a (mid-range): 4.1s → 2.8s
- Galaxy A10 (low-end): not tested

Memory usage at startup:
- 180MB → 150MB

**Testing**
Tests ran on 5 devices with Android 13 or 14. Low-memory devices were unavailable for testing.

**Known issue**
Navigating to the profile screen within 1s of launch causes a blank screen flash (~200ms). Logs indicate a race condition. This case has not been fixed in this PR.

---
*Note: Metrics for low-end devices and low-memory scenarios are missing from this run.*
