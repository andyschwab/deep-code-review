TLS 1.2→2.0 upgrade across 5 services: api_gateway handshake drops from 35 ms to 22 ms; auth_service from 40 ms to 25 ms.

**Why:** The old cipher suite `TLS_RSA_WITH_AES_128_CBC_SHA` is removed in version 2.0, improving security and performance.

**Change:**
- Upgraded shared lib and 4 services (auth, gateway, user, notification): +340, -210 lines.
- Removed deprecated `TLS_RSA_WITH_AES_128_CBC_SHA` suite.
- Full test suite passes for all services.

**Verified:** ✅ Benchmarks on api_gateway (35 ms → 22 ms) and auth_service (40 ms → 25 ms). ✅ All unit/integration tests pass. ⏳ Not tested: staging run with deprecated ciphers disabled.

**Risk:** The new library deprecates `TLS_ECDHE_RSA_WITH_AES_128_CBC_SHA`. Older mobile clients may still rely on it; usage data is unavailable.

**Open question for Security Lead:** Should we keep the deprecated `TLS_ECDHE_RSA_WITH_AES_128_CBC_SHA` cipher enabled for a transition period, or disable it immediately? We have not tested the upgrade on staging with this cipher disabled. Please review the diff and advise on the cipher strategy.
