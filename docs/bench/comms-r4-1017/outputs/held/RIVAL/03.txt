**Daily Project Update: API Rate-Limit Change**

The migration to the new public API rate limit (1,000 req/hr) is underway. The mobile client switched yesterday with no reported issues. The web client remains on the old limit (500 req/hr).

While the target date for the full switch is March 1, this is at risk. The web team has a release freeze until March 15, which will likely delay their update. Additionally, partner readiness is mixed. In testing, two of three partners handled the new limit successfully; one failed with 429 errors. We need to decide whether to grant that partner an exception or require them to update their integration.

The project sponsor and dev lead must approve the final rollout date and the exception policy. No recommendation is available yet.
