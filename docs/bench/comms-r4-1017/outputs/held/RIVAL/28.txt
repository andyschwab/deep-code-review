**Upgrade database driver and fix connection leak**

This PR upgrades the database driver and refactors the connection pool to resolve a memory leak that caused the service to consume an additional 200 MB per hour under load. With these changes, memory usage remains stable at approximately 500 MB over 24 hours.

**Changes**
- Updated `db_driver.py` and `connection_pool.py` to handle connection lifecycle correctly.
- Added `connection_leak_test.py` to verify memory stability during extended runs.
- Total scope: 7 files changed, +150/-60 lines.

**Risks and unknowns**
1. **Connection exhaustion:** The current tests do not cover the scenario where the pool is fully exhausted and must recover. We need to decide if a stress test for this specific case is required before merging.
2. **Config compatibility:** The new driver version may behave differently with our existing configuration. Please verify that the old config parameters remain valid or identify any necessary updates.
