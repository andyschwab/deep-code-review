**Fix flaky auth timeout with retry logic**

This PR stabilizes CI by addressing intermittent timeouts in the authentication service. We implemented a retry mechanism with exponential backoff in `ci_pipeline.py` and updated `integration_test.py` accordingly. A new test file, `test_retry_logic.py`, covers the successful retry paths.

**Results**
Across 200 runs in the last week, the pass rate improved from 78% to 96%.

**Open questions for review**
1. **Retry count:** The current implementation retries 3 times. Given the remaining failure rate, should we increase this to 5?
2. **Database failures:** Logs show two intermittent database connection failures. It is unclear if these are related to the auth timeout or a separate issue.
3. **Uncovered case:** The scenario where all retry attempts exhaust without success is not yet tested.

Sam, please advise on the retry count so we can finalize this before the release.
