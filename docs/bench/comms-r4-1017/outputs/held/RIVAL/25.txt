This PR refactors the thumbnail pipeline to improve throughput, increasing capacity from 150 to 220 images per minute on a standard 4-core machine. The changes span nine files, including modifications to `thumbnail_worker.py` and `image_processor.py`, and the addition of `worker_monitor.py`. Validation covered 10,000 images under normal conditions.

Two trade-offs require your decision before merging:

1.  **Error Handling:** The current implementation does not handle corrupt images; the worker will crash if it encounters one. We need to decide whether to add a fallback mechanism in this PR or accept the risk of failure for invalid files.
2.  **Memory Usage:** The optimizations increased memory consumption from 300 MB to 450 MB. Please confirm if this 50% increase is acceptable within our current infrastructure limits.

The performance gain is significant, but these risks need to be addressed or explicitly accepted.
