Upgraded the TLS library from version 1.2 to 2.0 across five services: auth_service, api_gateway, user_service, notification_service, and the shared lib. The update removes the old cipher suite `TLS_RSA_WITH_AES_128_CBC_SHA`.

Changes total +340 lines and -210 lines. The full test suite passes for all services.

Benchmarks on the api_gateway show handshake time improved from 35 ms to 22 ms on average, a 37% reduction. The auth_service saw a similar gain, dropping from 40 ms to 25 ms. The other services showed no significant change.

**Open question for the security lead**
The new library deprecates the cipher suite `TLS_ECDHE_RSA_WITH_AES_128_CBC_SHA`. We suspect a few clients, mostly older mobile apps, still use it, but we lack usage data. Should we keep this deprecated cipher enabled for a transition period or disable it immediately? Note that we have not yet tested the upgrade on a staging environment with this cipher disabled.

Please review the diff and advise on the cipher strategy.
