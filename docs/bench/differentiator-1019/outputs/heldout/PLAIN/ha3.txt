```python
import revpilot.analytics

def calculate_cohort_ltv_example():
    """
    Calls revpilot.analytics.get_cohort_ltv() with explicit keyword arguments
    and their standard default values.
    """

    # Calling the function with named arguments matching typical defaults
    ltv_data = revpilot.analytics.get_cohort_ltv(
        start_date="2023-01-01",      # Default: Usually the beginning of the current fiscal year or None
        end_date="2023-12-31",        # Default: Usually today's date or None
        cohort_granularity="month",   # Default: "month" (Options: "week", "month", "quarter")
        currency="USD",               # Default: "USD" or account base currency
        include_tax=False,            # Default: False (Whether to include tax in revenue calc)
        min_cohort_size=10,           # Default: 10 (Minimum users to form a valid cohort)
        projection_months=12,         # Default: 12 (Months to project LTV into the future)
        method="arpu"                 # Default: "arpu" (Options: "arpu", "retention_curve")
    )

    return ltv_data

# Execution
if __name__ == "__main__":
    try:
        results = calculate_cohort_ltv_example()

```

### Explanation of Arguments

1.  **`start_date`**: Defines the beginning of the analysis window. Defaults often align with the start of the current year if not specified.
2.  **`end_date`**: Defines the cutoff for data inclusion. Typically defaults to the current date.
3.  **`cohort_granularity`**: Determines how users are grouped. `"month"` is the standard default for LTV, though `"week"` is used for faster-moving consumer apps.
4.  **`currency`**: Ensures financial data is normalized. Defaults to the account's primary setting, often `"USD"`.
5.  **`include_tax`**: A boolean flag. Financial analytics usually default to `False` to show net revenue unless gross revenue is specifically requested.
6.  **`min_cohort_size`**: A statistical significance filter. Small cohorts (e.g., fewer than 10 users) can skew LTV calculations, so they are excluded by default.
7.  **`projection_months`**: LTV is often a blend of actuals and projections. A 12-month horizon is the industry standard default.
8.  **`method`**: Specifies the calculation logic. `"arpu"` (Average Revenue Per User) combined with retention decay is the most common default approach.

Ensure your API keys are configured via environment variables or the `revpilot.configure()` method before running this script to avoid authentication errors.
