*   **Lane A (Logic Implementation):**
    *   **Worker:** Builder.
    *   **Task:** Update campaign trigger logic to check user profile timezone (suppress 22:00–07:00 local) and query the global opt-out registry (exclude users opted out in last 48h).
    *   **Constraint:** Work in isolated worktree `wt-logic`. Do not touch database migration scripts yet.
*   **Lane B (Test Stabilization):**
    *   **Worker:** QA + Builder (Pair).
    *   **Task:** Fix `quiet-hour-validator` flakiness regarding Tuesday timezone mocking. Create a deterministic test case for the 48h opt-out window.

*   **Lane C (Integration & Dry-Run):**

    *   **Task:** Merge A and B. Run full CI. Execute database migration script in **dry-run mode only** against a local snapshot to verify irreversibility safety.
    *   **Serialization:** Must wait for A and B to pass unit tests locally.
