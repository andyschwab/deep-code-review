**Gates & Checks**

*   **G4 (Implement):** Builder commits to a feature branch `fix/refund-timeline-update`. Base SHA recorded.

If the 45-minute integration suite triggers, we will **not** skip it via commit message hackery; instead, we will monitor it. **Landing & Release**

*   **Merge Strategy:** Squash merge to `main` after G6 approval.
*   **Human Gate (G8 - Release):**
    *   **Blocker:** The auto-deployer pushes immediately upon merge, but the production deploy requires manual approval from the Site Reliability Lead.
    *   **Action:** Merge is **held** until 16:00 UTC when the Lead returns.

*   **Rollback:**
    *   Since this is a static asset change with immediate effect, rollback requires a revert commit and a re-deploy.
    *   **Plan:** If the string is incorrect or causes layout issues, immediately revert the merge commit. This requires the same human approval from the Site Reliability Lead.
