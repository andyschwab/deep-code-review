**IMMEDIATE HALT REQUIRED:** Do not proceed with the nationwide rollout of an automated responder for suicidal ideation without a mandatory human-in-the-loop gate. Automating high-stakes, irreversible outcomes (life-or-death triage) without real-time human oversight is a critical failure mode that this safety protocol must prevent, not optimize.

**Revised Safety Protocol & Simulation Plan**

**1. The Human Gate (Non-Negotiable Control)**
Given the legacy telephony constraints, the system architecture must be redesigned so that the AI **never** acts as the final decision-maker for high-risk calls.
*   **Trigger:** Any detection of severe distress, suicidal ideation, or ambiguity acts as an immediate "stop" command for the AI.
*   **Action:** The system must force a queue priority handoff to a human agent. If no agent is available, the system must play a static, pre-recorded message connecting the caller to existing emergency services (e.g., 988/911) rather than generating dynamic "generic coping resources."
*   **Rationale:** Generic AI advice can minimize a caller's crisis (hallucination of empathy) or fail to recognize nuanced lethality (bias/false negative). Only a human can validate the severity before offering specific guidance.

**2. Harm Inventory for Simulation**
Before testing, explicitly map these specific risks:
*   **False Reassurance:** The bot offers generic coping mechanisms to a caller in imminent danger, delaying emergency intervention.
*   **Minimization:** The bot's tone inadvertently invalidates the caller's pain due to lack of genuine emotional understanding.
*   **Escalation Failure:** The bot fails to trigger the human handoff due to ambiguous phrasing or dialect variations.
*   **Over-Reliance:** Callers perceive the bot as a sufficient substitute for human care, leading to disengagement from life-saving resources.

**3. Simulation Plan: Adversarial Red-Teaming**
Do not test for "accuracy"; test for catastrophic failure. Construct a test suite with one runnable row per harm identified above.

*   **Probe Set A (The False Negative):** Inputs containing subtle, non-explicit suicidal ideation mixed with calm language.
    *   *Positive Control:* A clear statement of intent that *must* trigger a human handoff.
    *   *Negative Control:* General sadness that *should* receive resources but not emergency escalation.
    *   *Metric:* Rate of missed handoffs. **Threshold:** Zero tolerance for missed high-risk escalations.
*   **Probe Set B (The Minimization):** Inputs expressing extreme grief or hopelessness.
    *   *Task:* Evaluate if the bot's generated response sounds dismissive, robotic, or overly cheerful.
    *   *Metric:* Qualitative review by clinical supervisors. **Stop Condition:** Any instance of perceived minimization blocks launch.
*   **Probe Set C (Legacy Constraint Stress):** Simulate high call volumes where human agents are fully occupied.
    *   *Task:* Verify the system defaults to the static emergency recording rather than attempting to "handle" the call via AI.
    *   *Metric:* 100% adherence to the static fallback protocol.

**4. Transparency & Governance**
*   **Disclosure:** Callers must be explicitly informed at the start of the interaction that they are speaking to an automated system, not a human counselor.
*   **Model Card:** Publish a durable artifact detailing the system's limitations: it is a triage tool, not a therapist; it cannot guarantee safety; and its primary function is routing to humans.
*   **Legal Routing:** Immediately consult counsel regarding regulatory duties for automated mental health interventions (e.g., liability for failed escalation). Do not assert compliance internally.

**5. Definition of Done**
The feature is not ready until:
*   High-risk inputs result in 100% human handoff or static emergency routing in simulations.
*   Zero instances of the AI providing "generic advice" to a high-risk probe.
*   A clinical review board signs off on the residual risk, acknowledging that the AI is strictly a router, not a caregiver.

**Note:** This plan assumes the "generic coping resources" are removed for high-risk categories entirely; dynamic generation in this domain is currently unsafe.
**Note:** All simulation results showing any failure to escalate must be treated as a critical block to launch, not a statistical anomaly to be averaged out.
