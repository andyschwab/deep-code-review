# SwiftPay P2P Feature Success Scorecard

## Primary Success Metrics

### Frequency & Engagement
- **Weekly Active Users (WAU) for P2P**: Users making ≥1 P2P transaction per week
- **Transactions per Active User (TPAU)**: Average monthly transactions per P2P user
- **Repeat Usage Rate**: % of users making ≥3 transactions within 30 days of first use

### Value & Revenue
- **Average Transaction Value (ATV)**: Track separately for first-time vs. repeat users
- **Total Volume Growth**: Month-over-month growth in total transaction value
- **Revenue per User**: Fees generated per active P2P user (if applicable)

### Retention & Progression
- **30/60/90-Day Retention**: % of users returning to make another P2P transaction
- **Progression Rate**: % of P2P users who subsequently make a traditional transfer >$50
- **Feature Adoption Depth**: % of users who both send AND receive via P2P

### Risk & Compliance
- **Failed Transaction Rate**: % of transactions flagged or reversed
- **Average Time to Resolution**: For disputed transactions
- **Compliance Incident Rate**: Reports per 10,000 transactions

## User Segmentation Framework

### By Transaction Behavior
1. **Micro-Users**: ATV <$20, high frequency (≥4/month)
   - Hypothesis: Building habitual engagement
   - Track: Progression to larger amounts over time

2. **Occasional Splitters**: ATV $20-$50, low frequency (1-2/month)
   - Hypothesis: True bill-splitting use case
   - Track: Consistency and seasonal patterns

3. **Hybrid Users**: Use both P2P and traditional transfers
   - Hypothesis: P2P as gateway to broader product usage
   - Track: Cross-feature adoption and lifetime value

### By User Journey Stage
1. **New Adopters** (0-30 days since first P2P)
   - Focus: Activation and early retention
   - Metric: Second transaction completion rate

2. **Established Users** (31-90 days)
   - Focus: Frequency building and value growth
   - Metric: Month-over-month transaction growth

3. **Mature Users** (90+ days)
   - Focus: Retention and cross-sell opportunities
   - Metric: Traditional transfer conversion rate

### By Social Network Effects
1. **Initiators**: Users who primarily send payments
2. **Receivers**: Users who primarily receive payments
3. **Connectors**: Users who both send and receive, creating network effects
   - Track: Network density (average connections per user)

## Success Thresholds for Next Two Quarters

### Q1 Targets (by end of Q2)
- P2P WAU reaches 15% of total user base (300K users)
- 40% of new P2P users make a second transaction within 14 days
- 25% of P2P users progress to traditional transfers >$50

### Q2 Targets (by end of Q3)
- P2P WAU reaches 25% of total user base (500K users)
- Average transactions per user increases from current baseline by 30%
- Hybrid users show 20% higher overall product engagement vs. non-P2P users

## Reporting Cadence for Risk & Compliance
- **Weekly**: Failed transaction rates, compliance incidents
- **Monthly**: All primary metrics with segmentation breakdowns
- **Quarterly**: Progression analysis, network effect measurements, ROI assessment

This balanced approach recognizes that small, frequent transactions may be the intended use case rather than a limitation. The key is determining whether this behavior drives long-term engagement and cross-product adoption, which would validate the feature's strategic value beyond immediate transaction revenue.

*Note: Baseline all metrics against the February 20th launch date for accurate cohort analysis. Consider implementing event tracking to capture the social context of transactions (e.g., first-time payer-receiver pairs vs. established relationships).*
