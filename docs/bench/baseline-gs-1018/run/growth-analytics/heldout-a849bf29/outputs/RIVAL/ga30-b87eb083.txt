# ReWear Italy: Day-One Tracking Plan (First 30 Days)

**Objective:** Validate market fit by measuring "Speed to First Sale" and Italian-specific negotiation behaviors to inform seller retention strategies.
**Reporting Cadence:** Weekly aggregates for Country Manager.

### 1. Core North Star: Speed to First Sale
*These events measure the primary hypothesis: faster first sales drive seller retention.*

| Event Name | Trigger | Essential Properties | Why It Matters |
| :--- | :--- | :--- | : |
| `listing_created` | User publishes an item. | `user_id`, `category`, `price`, `timestamp` | Establishes the supply baseline; starts the clock for "time to sale." |
| `first_sale_completed` | A seller's *first* ever transaction closes. | `user_id`, `days_to_first_sale`, `listing_category`, `sale_price` | **Primary Metric.** Directly measures the speed hypothesis. |
| `seller_returned` | A previous seller lists a second item. | `user_id`, `days_since_first_sale`, `previous_sale_count` | Proxy for retention; validates if the first sale drove continued activity. |

### 2. Critical Unknown: Negotiation Behavior
*These events isolate whether Italian users utilize negotiation features differently than the Spanish baseline.*

| Event Name | Trigger | Essential Properties | Why It Matters |
| :--- | :--- | :--- | :--- |
| `offer_made` | Buyer submits a price offer. | `listing_id`, `offer_amount`, `ask_price`, `user_location` | Measures demand-side negotiation aggression. |
| `offer_countered` | Seller responds with a counter-offer. | `listing_id`, `counter_amount`, `time_to_counter` | Measures seller willingness to engage vs. rejecting/ignoring. |
| `offer_accepted` | An offer is accepted (vs. full price). | `listing_id`, `final_price`, `discount_percentage` | Determines if sales volume relies on discounted negotiated prices. |
| `negotiation_abandoned` | Chat/Offer thread ends without sale after 48h. | `listing_id`, `last_action`, `highest_offer_vs_ask` | Identifies friction points where deals stall specifically in Italy. |

### 3. Funnel Health & Market Fit Signals
*Supporting events to diagnose *why* speed to sale is fast or slow.*

| Event Name | Trigger | Essential Properties | Why It Matters |
| :--- | :--- | :--- | :--- |
| `product_viewed` | User views a listing detail page. | `listing_id`, `referrer_source`, `device_type` | Measures demand intensity and traffic quality. |
| `chat_initiated` | Buyer messages seller about an item. | `listing_id`, `message_type` (auto/manual) | Early indicator of intent before an official offer is made. |
| `search_performed` | User executes a search query. | `query_text`, `result_count`, `filters_applied` | Reveals if Italian inventory matches local search intent (e.g., specific brands). |

### Implementation Notes for Country Manager
*   **Data Hygiene:** Ensure `user_location` is hardcoded to "IT" for all events in this container to allow immediate segmentation from Spanish data.
*   **Weekly Reporting:** Calculate "Median Days to First Sale" and "Offer Acceptance Rate" weekly; do not wait for month-end to spot deviations from the Spanish baseline.
