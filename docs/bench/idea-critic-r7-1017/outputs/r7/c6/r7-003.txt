**Recommendation to Mayor Luiza Ramos:**
Approve the Pixel Ledger project only as a **6-month, R$850,000 capped pilot** targeting the first 100,000 pages, with immediate release of funds contingent on correcting the budget arithmetic and establishing a dynamic staffing model. The current proposal contains a critical R$400,000 calculation error and an unverified assumption that 84,000 users (70% of 120,000) will migrate digitally, which risks significant sunk costs if adoption lags.

**Primary Failure Modes:**
1.  **Budget Overrun:** The proposal claims scanning 500,000 pages at R$0.80/page totals R$400,000, yet the spreadsheet lists R$800,000. This unresolved discrepancy suggests either the unit cost is actually R$1.60 or the total volume/cost is misstated, threatening the R$2.5M cap.
2.  **Low Adoption:** Assuming 70% user migration without a pre-launch marketing strategy or digital literacy program may result in an underutilized archive, failing the public value justification.
3.  **Staffing Gaps:** Scaling quality control from a 2-person pilot to full production without a defined ratio for error rates <1% could cause bottlenecks or degraded data quality.
4.  **Data Loss:** Hardware procurement (R$1.5M) lacks a specified redundancy or off-site backup protocol in the summary, risking the irreversible loss of historical assets.

**Pre-agreed Kill Criteria (Stop/Pivot Conditions):**
*   **Cost Trigger:** Halt immediately if the cost per page for the first 100,000 pages exceeds **R$0.90** (a 12.5% buffer over the R$0.80 estimate, rather than an arbitrary 10% of total budget).
*   **Adoption Trigger:** Pivot to a community-engagement focused model if active unique users remain below **15,000 (12.5% of registered base)** after six months of operation, indicating the 70% target is unrealistic.
*   **Quality Trigger:** Suspend scanning if error rates exceed **1.5%** for two consecutive weeks, requiring a process review before resuming.

**Notes:**
The R$400,000 vs. R$800,000 arithmetic conflict must be resolved with the vendor before any signature; do not present the current spreadsheet to the Mayor.
The "70% migration" figure should be presented to the Mayor as an aspirational goal, not a baseline fact, to maintain credibility.
