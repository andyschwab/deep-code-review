### Immediate Safety Net Plan for Telemedicine Bot

**1. Implement Hard Rule-Based Guards (Pre-Dispatch Filter)**
Since the NLP model cannot be updated, you must wrap its output in a deterministic code layer before any prescription reaches a patient or the EHR.
*   **Contraindication Matrix:** Build a static lookup table mapping known high-risk drug pairs and condition-drug conflicts (e.g., "Drug A" + "Symptom B" = BLOCK). This data should be sourced from your existing clinical guidelines, not the AI.
*   **Keyword Trigger Block:** Create a regex or exact-match filter for critical symptom descriptors that the bot historically misinterprets (e.g., "chest pain," "pregnant," "allergic to"). If the user input contains these triggers, the system must automatically bypass the AI's suggestion and flag the case for human review.
*   **Action:** If the AI suggests a medication that conflicts with the rule matrix or triggers a keyword block, the system returns a generic "Unable to process automatically" message to the user and routes the full transcript to a clinician queue. No prescription is generated.

**2. Enforce Mandatory Human-in-the-Loop (HITL) Gate**
Given the high-stakes nature of prescribing medication, fully autonomous execution is unsafe under current conditions.
*   **Universal Clinician Review:** For the initial launch phase, disable direct-to-patient prescribing. Every AI-generated recommendation must be presented to a licensed medical professional via a dashboard for explicit approval or rejection before being finalized.
*   **Uncertainty Escalation:** If the AI's internal confidence score (if available) is below a high threshold, or if the patient history contains complex comorbidities, the case is prioritized in the clinician queue.
*   **Override Mechanism:** Clinicians must have a one-click "Reject & Escalate" button that logs the error for later analysis without sending any output to the patient.

**3. Transparency and Disclosure**
*   **AI Disclosure:** Clearly inform patients that their treatment plan is being generated with AI assistance and reviewed by a human doctor. Do not present the AI's output as a final medical fact before review.
*   **Limitation Statement:** Internally document that the current NLP model has known failure modes regarding specific symptom interpretations, and that the rule-based guards are a temporary mitigation, not a permanent fix.

**4. Monitoring and Rollback Protocol**
*   **Real-Time Audit Log:** Log every input, AI suggestion, rule-block trigger, and human decision.
*   **Stop Condition:** Define a specific failure threshold (e.g., "If 3 near-miss contraindications are caught by human reviewers in 24 hours") that triggers an immediate pause on the automated suggestion feature, reverting to a fully manual intake process until the model can be updated.

**Note:** This plan treats the AI as a draft generator only, never an autonomous decision-maker, which is the required standard for high-stakes medical actions. Legal counsel should review the specific disclosure language to ensure compliance with Indian medical regulations and liability standards.
