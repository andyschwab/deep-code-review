**Pre-Launch Safety Plan: BorderSafe Pilot**

**1. Immediate Harm Inventory & Logic Freeze**
*   **Identify the Harm:** The current logic flags dual citizens as "high-risk" without justification. This constitutes **bias/unfair outcomes** (systematic disadvantage based on citizenship status) and **hallucination surfaced as fact** (presenting an arbitrary flag as a validated security threat).
*   **Action:** Immediately freeze the specific rule causing arbitrary dual-citizen flags. Do not ship this logic in its current state.
*   **Worst Case:** Wrongful denial of entry, detention, or severe delay for innocent travelers; legal liability and loss of public trust.

**2. Implement a Human-in-the-Loop (HITL) Gate (Non-Negotiable)**
*   **Constraint:** Since retraining is impossible before the deadline, you cannot rely on the model to self-correct.
*   **Control:** Any "high-risk" flag generated by the system must trigger a **mandatory human review** by a senior border agent before any action (detention, secondary screening) is taken.
*   **Rule:** The system acts only as a *suggestion engine* for the pilot. It must never execute an irreversible action (like blocking entry) autonomously. The agent makes the final decision.

**3. Define and Surface Uncertainty**
*   **Remove False Precision:** Do not display raw confidence scores (e.g., "87% risk") to agents or travelers.
*   **Adopt Coarse Tiers:** Replace numeric scores with defined text tiers accompanied by color cues:
    *   *Confirmed:* Multiple independent data points match.
    *   *Corroborated:* One strong signal + context.
    *   *Unverified/Arbitrary:* Single signal or known weak heuristic (e.g., dual citizenship alone).
*   **Interface Change:** If a flag is based solely on the disputed logic, the UI must explicitly state: "Flag based on unverified heuristic. Requires manual validation."

**4. Rapid Measurement Plan (No Retraining Required)**
*   **Adversarial Probe Set:** Construct a test set using historical data containing:
    *   *Positive Controls:* Known security risks (to ensure the system still catches real threats).
    *   *Negative Controls:* Innocent dual citizens (to measure the false positive rate of the current logic).
*   **Metric:** Calculate the "Arbitrary Flag Rate" specifically for dual citizens.
*   **Stop Condition:** If the system flags >0% of innocent dual citizens as "high-risk" without additional corroborating evidence, the automated suggestion feature for this specific category must be disabled until rules are refined.

**5. Transparency Artifacts (Model & Data Cards)**
*   **Draft a Model Card:** Before launch, publish an internal document stating:
    *   *Intended Use:* Decision support for border agents only.
    *   *Limitations:* Explicitly note that "dual citizenship" is currently a weak predictor and generates high false positives.
    *   *Owner:* Name the specific engineer responsible for monitoring these flags.
*   **Data Card:** Document the provenance of the legacy database fields being used. Note any known gaps or biases in the historical data regarding citizenship status.

**6. Governance & Legal Routing**
*   **Owner Assignment:** Assign one engineer as the "Harm Owner" for bias-related incidents. They must review all flagged cases weekly.
*   **Legal Referral:** The classification of travelers based on citizenship may trigger regulated automated decision-making laws (e.g., EU AI Act, local constitutional protections). **Route immediately to legal counsel** to determine if this specific logic requires statutory disclosure or is prohibited entirely. Do not assert compliance internally; let counsel define the duty.

**Summary of Next Steps:**
1.  Disable autonomous action on dual-citizen flags; enforce human review.
2.  Run the probe set against legacy data to quantify the false positive rate.
3.  Publish the Model Card highlighting this specific limitation.
4.  Engage counsel regarding the legality of citizenship-based profiling.

*Note: This plan treats the deadline as fixed but refuses to certify the system as "safe" or "unbiased" given the current logic. The human gate is the primary control.*
*Do not proceed to wider rollout until the "Arbitrary Flag Rate" is measured and the HITL process is verified in live drills.*
