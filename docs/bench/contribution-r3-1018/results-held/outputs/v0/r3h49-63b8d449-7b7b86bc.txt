**Description:**

This PR resolves a memory leak in the navigation module where `PathPlanner` instances were not properly releasing trajectory buffers after replanning events. The fix ensures buffers are cleared in the `reset()` method, preventing unbounded memory growth during long-running autonomy sessions.

**Technical Details:**

- **Fix:** Added explicit buffer cleanup in the `PathPlanner::reset()` method and verified proper RAII semantics for temporary allocations.
- **Testing:** Validated on synthetic navigation scenarios (10k replanning cycles) showing stable memory usage (<2MB variance) versus previous unbounded growth. No functional behavior changes observed.
