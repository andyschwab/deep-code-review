**Proposed Pull Request Description**

**Title:** Fix persistent memory leak in frame buffer release cycle

**Problem**
During extended real-time streaming workloads, the `VideoFlow` library fails to release intermediate buffers after frame processing completes. This results in unbounded memory growth, observed as an increase from a stable baseline to approximately 4 GB during standard stress testing, eventually leading to process termination or system swapping.

**Solution**
This patch corrects the buffer lifecycle management in the processing pipeline. The fix ensures that all allocated frame buffers are explicitly released immediately after the consumer callback returns, regardless of the exit status of the processing stage. The change modifies the ownership transfer logic to prevent orphaned allocations in the memory pool.

**Verification & Impact**
The fix was validated using a synthetic workload that mimics high-throughput streaming patterns without relying on proprietary codecs or application-specific data structures.

*   **Test Method:** A standalone harness was created to inject dummy frames at maximum throughput for 30 minutes. Memory usage was monitored via standard OS-level tools (e.g., `valgrind` massiff or `/proc/[pid]/status`) rather than application-specific introspection tools.
*   **Results:**
    *   **Before Patch:** Memory usage grew linearly, reaching ~4 GB after the test duration.
    *   **After Patch:** Memory usage remained stable at ~200 MB throughout the entire test, representing a >95% reduction in peak memory footprint.
*   **Evidence:** Due to the use of internal, proprietary variable naming in the original debugging sessions, raw heap dumps and screenshots cannot be shared publicly. However, the stability of the memory footprint in the synthetic test confirms the leak is resolved. The test harness and scripts used to generate these numerical results are included in the `tests/` directory of this PR for independent verification.

**Risk**
Low. The change is localized to the buffer deallocation path. Existing unit tests pass, and the synthetic stress test confirms no regression in throughput or stability.
