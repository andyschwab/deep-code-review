**Title:** Fix memory leak in navigation module's path planning cache

**Description:**

This PR resolves a memory leak in the navigation module where cached path plans were not properly released after timeout, leading to gradual memory growth during long-running autonomous sessions. The fix ensures proper cleanup of stale cache entries while maintaining performance characteristics.

**Technical Summary:**
- Identified unbounded growth in `PathCache` during extended operation (>4 hours)
- Added TTL-based eviction and explicit cleanup on navigation goal completion
- Verified fix reduces memory growth from ~50MB/hour to <2MB/hour in stress tests
- No changes to public API or navigation behavior

**Testing:**
- Ran 12-hour continuous navigation test on synthetic warehouse map
- Memory profile shows stable RSS after fix vs. linear growth before
- All existing navigation tests pass; added regression test for cache cleanup
