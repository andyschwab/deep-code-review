**Proposed Example Structure: Synthetic Data with Mocked I/O**

To satisfy the requirement for runnable, safe examples without exposing internal endpoints or requiring complex user setup, replace real database connections with a **local, in-memory synthetic data generator** and **mocked network layers**. This pattern allows the code to execute end-to-end in the CI environment using only standard library dependencies or the library itself, while demonstrating the exact streaming architecture you intend to teach.

**1. The Pattern: `FakeSource` and `MemorySink`**
Instead of connecting to `jdbc:postgresql://dev-cluster.initech...`, create a lightweight helper class within the example (or import a provided test utility) that yields deterministic, synthetic records. This mimics the latency and chunking of a real stream without touching the network.

```python
# examples/streaming_pattern.py
import time
from typing import Iterator, Dict, Any

# 1. Synthetic Source: Replaces real DB/API connection
class SyntheticStream(Iterator[Dict[str, Any]]):
    def __init__(self, count: int = 100):
        self.count = count
        self.current = 0

    def __iter__(self):
        return self

    def __next__(self) -> Dict[str, Any]:
        if self.current >= self.count:
            raise StopIteration
        # Generate deterministic, safe data
        record = {
            "id": self.current,
            "timestamp": time.time(),
            "value": (self.current * 3.14) % 100,
            "status": "active" if self.current % 2 == 0 else "idle"
        }
        self.current += 1
        return record

# 2. The Processing Logic (The core lesson)
def process_stream(source: Iterator[Dict[str, Any]]) -> None:
    """Processes incoming data chunks efficiently."""
    batch = []
    for record in source:
        # Transform logic here
        record["processed"] = True
        batch.append(record)

        # Simulate windowing or batching behavior
        if len(batch) >= 10:
            # In real usage, this would write to a sink
            print(f"Processed batch of {len(batch)} items")
            batch = []

if __name__ == "__main__":
    # 3. Execution: Fully runnable, zero external deps
    print("Starting synthetic stream processing...")
    source = SyntheticStream(count=50)
    process_stream(source)
    print("Stream complete.")
```

**2. Addressing the "Realism" Concern**
Users learn the *pattern* of streaming (iteration, batching, backpressure), not the specific credentials of your cluster. To demonstrate error handling or connection logic, use Python's `unittest.mock` within the example to simulate connection failures or latency spikes, which is often more educational than a flaky real connection.
