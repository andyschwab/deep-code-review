**TLS 1.3 Upgrade: Config Changes and Cipher Suite Decision Needed**

This PR upgrades the TLS library from version 1.2 to 1.3 across all 12 services. The change is primarily configuration-based, resulting in a net addition of 10 lines (+60, -50) across service configs and the shared TLS setup.

Average handshake time dropped from 40ms to 25ms, a 37% reduction. The full test suite passed (230 tests) with no new tests required.

2.  Keep it temporarily to support older clients.
