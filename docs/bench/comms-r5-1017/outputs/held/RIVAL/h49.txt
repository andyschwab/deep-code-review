This PR lazy-loads the analytics, chat, and settings modules to cut mobile startup time. On a mid-range device, startup dropped from 3.5s to 2.1s (40% improvement). Specific results: Pixel 7 (3.2s → 1.9s) and Samsung A13 (4.1s → 2.6s). The change touches six files (entry point, loader, four feature modules) with +180/-90 lines. All 90 existing tests pass, plus three new tests for the loader.

Two risks need your call:
1. **Low-memory devices:** We haven't tested on devices with <2GB RAM. On-demand loading could cause memory pressure. Please review the strategy to decide if we need low-memory testing or if the current approach is safe.
2. **Chat module latency:** We're unsure if the chat module loads fast enough when opened. Please verify the loading strategy feels responsive.
