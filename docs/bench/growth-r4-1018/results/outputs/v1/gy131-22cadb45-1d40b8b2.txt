**Recommendation: Halt Global Rollout; Run a Targeted Validation Sprint**

Do not proceed with the global rollout next month. The conflicting signals (CTR +50%, Dwell Time -62%) indicate a high probability of "clickbait" behavior where the new algorithm promotes misleadingly titled results that users immediately abandon. The assumption that "faster access" explains the drop is `UNVERIFIED` without evidence of task completion. Prioritize the following three metrics to distinguish between genuine efficiency and false positives:

1.  **Search Success Rate (Zero-Result & Reformulation Rate)**
    *   **What to measure:** The percentage of sessions where a user clicks a result but returns to the search page within 10 seconds to either click a different result or re-type the query.
    *   **Interpretation:** If this rate has increased since Oct 15, the drop in dwell time confirms users are bouncing because the first click was irrelevant. A genuine efficiency gain would show stable or lower reformulation rates.
    *   **Action:** If reformulation > 15% of post-click sessions, the ranking is degrading utility.

2.  **Task Completion Proxy (Downstream Action Rate)**
    *   **What to measure:** The frequency of specific "success" events on destination pages (e.g., clicking "Copy Code," downloading a PDF, or visiting a secondary linked doc) per search session, rather than raw time spent.
    *   **Interpretation:** If users find answers faster, downstream actions should remain stable or increase despite lower dwell time. If downstream actions have dropped proportionally to dwell time, users are leaving without solving their problem.
    *   **Action:** Correlate this metric against the new ranking score. A negative correlation confirms the algorithm is surfacing low-value content.

3.  **Qualified Dwell Time Cohorts**
    *   **What to measure:** Segment dwell time by user intent (e.g., "known-item search" vs. "exploratory search") if identifiable, or by document type (API reference vs. conceptual guide).
    *   **Interpretation:** A drop from 4m to 90s is plausible for API lookups but suspicious for conceptual guides. If the drop is uniform across all content types, it signals a systemic relevance failure, not an efficiency win.
    *   **Action:** Isolate the drop to specific content categories. If conceptual guides show <2 minute dwell, the titles are likely misleading.

**Decision Framework for Leadership**
*   **Ship:** Only if *Search Success Rate* is flat/improved AND *Downstream Action Rate* is stable. This proves users are getting value faster.
*   **Stop & Revert:** If *Search Success Rate* has worsened OR *Downstream Actions* have dropped >10%. This proves the CTR gain is vanity driven by misleading snippets.
*   **Extend Test:** If data is inconclusive due to low volume, extend the current pilot for 14 days with explicit instrumentation for the metrics above. Do not guess; the current data is insufficient to claim success.
