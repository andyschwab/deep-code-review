### Behavioral Metrics Plan for Power User Retention

**Audience:** Design Lead
**Goal:** Determine if the UI update causes functional friction leading to churn risk, informing a decision to revert or introduce a "Classic" mode by month-end.

**1. Primary Diagnostic: Task Efficiency Delta**
Do not rely on generic "session time." Measure **Time-to-Complete** for the top 5 core workflows that drive your 40% revenue (e.g., "Create Complex Gantt," "Bulk Edit Dependencies").
*   **The Query:** Compare the median duration of these specific workflows for the power-user cohort (top 5% by historical activity) in the 30 days pre-launch vs. post-launch.
*   **The Reading Rule:** If Time-to-Complete has increased by >15% while error rates (undo actions, failed saves) remain flat, the hypothesis of "hidden features/click fatigue" is confirmed. If duration is up but errors are also up, the issue is confusion, not just layout.

**2. Secondary Diagnostic: Feature Accessibility Friction**
Validate the "hiding" assumption by measuring **Path Depth** and **Search Reliance**.
*   **The Query:** Track the number of clicks/navigation events required to reach advanced features from the dashboard. Simultaneously, measure the frequency of internal search queries for those specific feature names.
*   **The Reading Rule:** A significant increase in path depth or a spike in search queries for known features indicates discoverability failure. If users are searching but not clicking, the feature is effectively invisible.

**3. Leading Indicator of Churn: Regression Frequency**
Session time drops can mean efficiency or abandonment. Distinguish them by measuring **Regression to Old Patterns** (if logs allow) or **Partial Task Abandonment**.
*   **The Query:** Calculate the rate of started-but-unsaved complex tasks. Also, track if power users are bypassing the new UI entirely (e.g., using API imports or mobile apps if those weren't updated) to achieve the same outcome.
*   **The Reading Rule:** A rise in abandonment rates >5% is a critical churn signal. Adaptation looks like stable completion rates despite longer times; churn risk looks like incomplete workflows.

**Decision Matrix for Month-End Deadline**
*   **Revert All:** If Time-to-Complete is up >20% AND Abandonment is up >5%. The friction is destroying value faster than adaptation can occur.
*   **Build "Classic" Mode:** If Time-to-Complete is up >15% but Abandonment is flat. Users are frustrated but forcing it through; they will leave if a competitor offers ease.
*   **Hold & Iterate:** If Time-to-Complete is up <10% and Search reliance is normal. The 20% session time drop may be unrelated to task friction (e.g., external market factors); do not ship a revert based on anecdote alone.

**Immediate Next Steps (This Week)**
1.  **Define the Top 5 Workflows:** List the exact event chains that constitute your revenue-generating tasks by Tuesday.
2.  **Run the Efficiency Delta Query:** Pull the pre/post comparison for these chains specifically for the top 5% cohort.
3.  **Set the Tripwire:** If the data shows >15% efficiency loss, commit to scoping "Classic" mode immediately; do not wait for further anecdotal evidence.

*Note: All metrics must be compared against your own pre-launch baseline; no external benchmarks apply here. Ensure user identifiers are pseudonymous when slicing this cohort.*
