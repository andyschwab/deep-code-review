**To:** Design Lead
**From:** Growth Analytics
**Subject:** Urgent Metric Plan: Power User Retention & UI Friction

**Decision Framework**
Do not revert the UI or build "Classic Mode" based on session time alone. Session time is ambiguous; a drop can mean frustration (unable to find features) or efficiency (faster completion). We must distinguish between *struggle* and *speed* before acting. The following metrics will determine the path by end-of-month.

**1. Primary Diagnostic: Task Completion Rate & Time-to-Value (Not Session Time)**
Stop measuring "session time." Instead, measure the **completion rate** and **time-to-complete** for the top 3 core workflows power users execute daily (e.g., "Create Gantt Chart," "Assign Dependencies," "Generate Report").
*   **The Read:**
    *   If **Completion Rate drops** AND **Time-to-Complete rises**: The UI is broken for them. They are struggling. **Action:** Prioritize immediate hotfixes for those specific flows; consider a temporary "Classic" toggle if fixes exceed 2 weeks.
    *   If **Completion Rate holds steady** BUT **Time-to-Complete drops**: The UI is *more* efficient. The session time drop is a win, not a loss. **Action:** Ignore anecdotal complaints about "feeling" slower; show them the efficiency data.
    *   If **Completion Rate holds** AND **Time-to-Complete rises**: They are adapting to a new path. **Action:** Monitor for one more week; do not revert yet.

**2. Secondary Diagnostic: Feature Discovery & Error Loops**
Measure the **clicks-per-task** and **error/backtrack rate** (e.g., opening a menu, closing it, trying another) for advanced features.
*   **The Read:** A spike in backtracks or "dead-end" clicks confirms the "hiding features" hypothesis.
*   **The Read:** If clicks are higher but backtracks are low, the new path is just longer, not confusing.

**3. The Churn Leading Indicator: Cohort Retention of Core Action**
Do not wait for churn. Track the **weekly retention of the core action** specifically for the power-user cohort (top 5% revenue).
*   **The Read:** If they complete the core action less frequently week-over-week, adaptation is failing, and churn is imminent. If frequency is stable, they are adapting despite complaints.

**This Week's Steps**
1.  **Query Immediately:** Pull completion rates and time-to-complete for the top 3 power-user workflows, segmented by "Pre-Launch" vs. "Post-Launch" for the top 5% revenue cohort.
2.  **Define the Tripwire:** If completion rate for any core workflow has dropped >5% compared to their own baseline, flag for immediate design intervention. If completion is stable, schedule a demo showing efficiency gains to key accounts to quell anxiety.
3.  **Instrument Gap:** If "error/backtrack" events are not currently tagged, add a temporary tag to the top 5 navigation elements power users touch to capture hesitation within 48 hours.

**Note:** All benchmarks above compare the power users to their own pre-launch baseline; no external industry standards apply here. Do not fabricate a "good" retention number; the trend line is the only truth.
