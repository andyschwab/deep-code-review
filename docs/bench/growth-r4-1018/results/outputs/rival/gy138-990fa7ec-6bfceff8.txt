### SmartFilter Activation Definition

**Activation Event:** `smartfilter_activated`

A user is considered **Activated** when they complete **any one** of the following three distinct behavioral sequences within 14 days of their first document upload. These criteria distinguish between passive exposure and genuine reliance on the model's output.

#### Criterion A: The "Search Reliance" Sequence
*Signals the user trusts the model enough to use it for retrieval.*
1.  User uploads a document (triggering auto-tagging).
2.  User performs a search query using **at least one** auto-generated tag as a filter or keyword.
3.  User clicks on a search result returned by that tag query.
*   **Threshold:** 1 completed sequence.

#### Criterion B: The "Organization" Sequence
*Signals the user accepts the model's categorization for structure.*
1.  User views the auto-generated tags on a document.
2.  User moves the document into a folder/category that matches an auto-generated tag OR applies an auto-generated tag to a second document manually.
3.  User accesses that folder or tagged view again within 48 hours.
*   **Threshold:** 1 completed sequence.

#### Criterion C: The "Repeated Utility" Frequency
*Signals habitual reliance rather than accidental interaction.*
1.  User interacts with an auto-generated tag (click, filter, or expand).
2.  User repeats this specific interaction type on **3 separate occasions** across **2 different days**.
*   **Threshold:** 3 interactions over 2+ days.

### Implementation & Dashboard Metrics

**Primary Metric:** Activation Rate
*   *Formula:* (Users who triggered `smartfilter_activated` within 14 days of first upload) / (Total users who uploaded ≥1 document).
*   *Target Baseline:* Shift from current 15% interaction rate to a defined activation rate (e.g., aim for 25% of uploaders).

**Secondary Metrics for Monitoring:**
*   **Time-to-Activation:** Average days from first upload to meeting one of the above criteria.
*   **Sequence Breakdown:** Percentage of activations driven by Search vs. Organization vs. Frequency (helps tailor onboarding messaging).
*   **False Positive Check:** Track users who click a tag once but never return to that view within 24 hours (excludes accidental clicks).

**Data Properties to Capture:**
*   `activation_method`: "search_reliance" | "organization" | "repeated_utility"
*   `days_to_activate`: Integer
*   `tags_interacted_with`: Array of tag strings (to identify high-value tags)

This definition ensures your Customer Success team targets users who have *used* the value, not just seen it, allowing for onboarding emails that reinforce specific behaviors (e.g., "See how others use tags to search faster" for non-activated users).

*Note: Ensure your analytics tool distinguishes between system-generated tag views (passive) and user-initiated clicks (active) to prevent inflating the baseline.*
*Review these thresholds after the December 10th launch; if <5% of users hit Criterion C, consider lowering the frequency requirement to 2 interactions.*
