**What Flips It, and the Trigger:**
The deciding factor is whether the software applies **legal judgment** to specific facts or merely fills blanks. Regulators use a "fact-specific application" test: if the software asks user-specific questions and selects clauses based on those answers to create a valid will, it is practicing law. If it provides blank forms with generic instructions, it is usually permissible.
*   **Trigger:** The moment a user in California or New York completes a workflow that outputs a signed, witnessed document without review by an attorney licensed in *that* state.
*   **Rule of Thumb:** If the output looks like a lawyer drafted it for that specific person, you are acting as the lawyer.
