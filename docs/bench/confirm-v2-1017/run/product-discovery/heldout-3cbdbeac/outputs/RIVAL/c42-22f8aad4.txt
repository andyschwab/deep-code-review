# Advisory Board Summary: NordShop Recommendation Engine Review

**Executive Decision:** Pause all model retraining and algorithmic improvements immediately. The data indicates a fundamental **Usability and Value risk**, not a Feasibility or data volume issue. Retraining the model with more historical data will likely yield diminishing returns while burning the remaining $20,000 budget on a feature that is actively harming core metrics (15% drop in session duration).

**Opportunity Cost Analysis**
Continuing down the current path of "better algorithms" incurs severe opportunity costs:
1.  **Revenue Erosion:** The 15% reduction in session duration suggests users are disengaging from the core shopping experience. Every day the feature remains in its current state, we lose potential sales from existing high-intent browsing.
2.  **Budget Misallocation:** Spending the remaining $20,000 on data science hours to fix a placement/UX problem diverts funds from high-impact experiments, such as A/B testing alternative UI placements or removing the feature to restore baseline engagement.
3.  **Technical Debt:** Accumulating complex logic for a feature users ignore creates long-term maintenance burdens without corresponding value.

**Strategic Recommendation**
Shift focus from **Feasibility** (can we build a better model?) to **Value** (do users want recommendations here?) and **Usability** (is the placement intrusive?).
*   **Immediate Action:** Run an A/B test removing the recommendation engine for 50% of traffic to confirm if session duration recovers.
*   **Secondary Action:** If removal boosts metrics, redesign the placement as a non-intrusive "discovery" module rather than a home-screen dominant element.

**Target User Segments for Interviews**
To validate the hypothesis that placement is the friction point, conduct rapid interviews (5–7 users per segment) with the following groups:

1.  **The "Bounce" Segment:** Users who visited the home screen post-launch but had session durations <30 seconds.
    *   *Goal:* Understand immediate friction. Did the recommendations confuse them or obscure search/navigation?
2.  **The "Ignore" Segment:** Power users (high purchase history) who have not clicked a single recommendation impression in the last 30 days.
    *   *Goal:* Determine if the recommendations are irrelevant or simply invisible due to "banner blindness."
3.  **The "Churned" Segment:** Previously active users who have not returned since the feature launch.
    *   *Goal:* Assess if the new home screen experience was the catalyst for leaving.

**Next Steps**
Allocate $2,000 of the budget for rapid user interviews and the remaining $18,000 toward UI/UX experimentation and potential feature redesign, contingent on interview findings. Do not release further funds to the data science team for model retraining until user behavior validates the need for better logic.

***

*Note: This summary assumes the 15% session drop is statistically significant and directly correlated with the feature launch. Ensure data cleanliness before presenting to the board.*
