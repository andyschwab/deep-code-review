# Usability Failure Briefing: Bangkok Bazaar Mobile App

**Current Evidence Status**
Fifteen participants tested the prototype. Eight failed to locate the checkout button within ten seconds; five abandoned the task entirely. This indicates a critical friction point in the conversion funnel.

**The Unknown Variable**
The data confirms *that* users are failing, but not *why*. Your stated assumption is that the menu structure is the primary cause. However, the current evidence cannot distinguish between:
1.  **Label Confusion:** Users do not understand the navigation terms.
2.  **Visual Hierarchy Failure:** The button exists but is visually obscured or lacks contrast.

**Riskiest Assumption Gate**
Before approving a "complete navigation redesign," we must test the assumption that *structure* is the root cause. A full redesign is high-effort and high-risk before the March 10th campaign. If the issue is merely visual hierarchy, a structural overhaul is wasted effort that delays the launch unnecessarily.

**Recommended Immediate Action: The Cheap Test**
Do not redesign yet. Run a **5-minute isolated visual test** with 5 new users (or re-engage 5 from the original pool if possible) before any code is written:
*   **The Test:** Show users a static screenshot of the current screen with the instruction: "Tap where you would go to pay."
*   **The Metric:** Time-to-tap and success rate.
*   **The Kill Threshold:** If >4 of 5 users tap the correct area immediately, the structure is fine; the issue is visual hierarchy (fix with CSS/layout tweaks). If they still fail or tap the wrong area, the labels/structure are broken, justifying a deeper redesign.

**Decision Framework for March 10th Launch**

| Scenario | Evidence Required | Recommendation | Risk of Delaying Launch | Risk of Shipping Flawed |
| :--- | :--- | :--- | :--- :--- :--- |
| **Visual Hierarchy Issue** | Users find the button instantly on static image but fail in flow. | **Ship with Tweaks.** Adjust contrast, size, or placement only. | **High.** Unnecessary delay misses campaign traffic. | **Low.** Minor visual fixes can be hot-fixed post-launch. |
| **Structural/Label Issue** | Users cannot identify the checkout action even on static image. | **Pivot Scope.** Simplify flow to a single "Buy Now" entry point; defer full redesign. | **Medium.** Requires focused dev time, but avoids launching a broken core loop. | **Critical.** Campaign traffic will abandon at the same 33%+ rate; marketing spend is wasted. |
| **Untested Assumption** | No further testing performed; team guesses the cause. | **Refuse Decision.** Do not commit to full redesign or launch until the specific failure mode is isolated. | **Unknown.** | **Maximum.** Building the wrong solution guarantees failure. |

**Strategic Recommendation**
Do not authorize a complete navigation redesign today. The cost of a full rebuild risks missing the March 10th window, and if the problem is only visual, it is over-engineering.

1.  **Run the static screenshot test immediately** (results expected within 24 hours).
2.  **If Visual:** Apply high-contrast tweaks and proceed to launch.
3.  **If Structural:** Implement a "Concierge" style fix (e.g., a prominent, hard-coded "Checkout" banner on the home screen) to bypass the broken menu for the campaign, while scheduling the full redesign for post-campaign.

Launching with a known 33%+ abandonment rate on checkout is unacceptable. However, launching with a *hypothesized* fix is equally dangerous. Isolate the variable first.
