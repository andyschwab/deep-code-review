### ClearFlow Utilities Pre-Deployment Session Plan

**Immediate First Action: Secure the Facility**
Isolate all four facilities from the live water network immediately by engaging manual bypass valves and locking out automated dosing pumps. Physically disconnect the new control system's output relays until final sign-off is granted. No digital access or software installation proceeds until this mechanical isolation is verified and tagged by the lead engineer at each site.

**Phase 1: Baseline Calibration (Hours 0–24)**
*Objective: Establish safe sensor baselines without active dosing.*
1.  **Data Analysts (Remote):** Generate simulated input profiles for all 50 million gallons of daily flow scenarios. Load these into the sandbox environment to verify algorithmic responses.
2.  **Field Engineers (On-Site):** Install sensor hardware at all four facilities. Perform dry-run calibration using certified reference standards only. **Strict Prohibition:** Do not connect sensors to the active dosing logic yet.
3.  **Verification:** Analysts compare dry-run sensor telemetry against reference standards. Any deviation >0.5% triggers an immediate halt for recalibration.

**Phase 2: Closed-Loop Simulation (Hours 24–48)**
*Objective: Validate system logic with isolated hardware.*
1.  **Field Engineers:** Connect sensors to the control logic but keep the final output relays physically disconnected (open circuit).
2.  **Data Analysts:** Inject the simulated flow profiles into the live-connected system. Monitor the system's *intended* dosing commands.
3.  **Verification:** Analysts confirm that calculated dosing commands match safety parameters exactly. Field engineers verify that no physical voltage is reaching the pumps despite system commands.

**Phase 3: Controlled Live Integration (Hours 48–58)**
*Objective: Minimal viable live test.*
1.  **Field Engineers:** Engage output relays at Facility A only (lowest volume). Set system to 10% capacity mode.
2.  **Data Analysts:** Monitor real-time chemical levels in Facility A's outflow every 5 minutes.
3.  **Verification:** If Facility A remains stable for 4 hours, replicate sequentially at Facilities B, C, and D. If any anomaly occurs, revert to manual bypass immediately.

**Task Delegation Matrix**
*   **Field Engineers:** Responsible for physical isolation, hardware installation, manual valve operations, and confirming zero-voltage states on pump inputs. They hold the "Physical Kill Switch."
*   **Data Analysts:** Responsible for generating test data, monitoring telemetry streams, validating algorithmic outputs against safety thresholds, and authorizing the transition between phases. They hold the "Digital Permission Gate."

**Mandatory Safety Parameters for Lead Approval**
Before touching live controls, you must personally sign off on:
1.  **Mechanical Isolation Certificate:** Written confirmation from all seven engineers that manual bypasses are active and output relays are physically disconnected.
2.  **Baseline Variance Report:** Data analyst certification that sensor readings match reference standards within 0.5% tolerance during dry runs.
3.  **Emergency Flush Protocol:** Verified readiness of the manual flush valves to purge the network within 15 minutes if overdosing is detected.
4.  **Rollback Trigger:** A defined metric (e.g., any single reading exceeding 110% of target) that mandates immediate system shutdown and reversion to manual control.

**Note:** This schedule leaves a 2-hour buffer before the Thursday 10 AM council observation for final system stabilization.
**Note:** Under no circumstances should baseline values be entered while the system is connected to active dosing pumps.
