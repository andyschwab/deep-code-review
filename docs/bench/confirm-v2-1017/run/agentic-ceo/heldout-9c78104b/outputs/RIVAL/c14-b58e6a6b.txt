**Immediate Work Session Plan: Northwind Logistics Payroll Consolidation**

**Phase 1: Preparation (Days 1–2)**
*Objective: Freeze data and validate logic without touching live accounts.*
1.  **Data Freeze & Extraction:** Halt all non-essential changes in the four legacy systems. Extract a complete snapshot of employee records, bank details, and tax histories for all 210 staff.
2.  **Mapping Verification:** The lead developer must map legacy data fields to the new unified system schema. Focus strictly on country-specific tax codes and bank formatting rules for the three operational regions.
3.  **Risk Isolation:** Identify the top 10% of complex payrolls (executives, cross-border workers, variable commission) for manual verification later.

**Phase 2: The Dry Run (Day 3)**
*Objective: Execute a full simulation to catch errors before the irreversible cutover.*
1.  **Shadow Processing:** Run the payroll calculation in the new system using the frozen data snapshot. Do not initiate any bank transfers.
2.  **Reconciliation:** The two-person finance team compares the new system's output against the last successful payslips from the four old providers. Any discrepancy greater than $0.00 triggers an immediate halt and code review.
3.  **Compliance Check:** Verify that tax withholdings for all three countries match current legal requirements based on the simulated output.

**Phase 3: Execution & Cutover (Days 4–5)**
*Objective: Irreversible transfer and live payment.*
1.  **Final Data Sync:** Perform the final delta sync to capture any mandatory changes since the freeze.
2.  **The Cutover:** Transfer sensitive bank details and tax histories to the new provider. Close read-only access to old accounts immediately after validation.
3.  **Live Disbursement:** Authorize the salary run for the 30th. Monitor the first hour of transaction processing closely for rejection notices.
