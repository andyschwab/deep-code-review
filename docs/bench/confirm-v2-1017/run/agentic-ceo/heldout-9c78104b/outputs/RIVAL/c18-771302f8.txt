**Pre-Shutdown Planning Session Workflow: Oakhaven Energy Monitoring Upgrade**

**Phase 1: Preparation (Immediate Action through March 9)**
*Objective: Finalize the offline environment and validate the rollback strategy.*
1.  **Air-Gap Verification:** Confirm the complete physical and logical isolation of the target control network. No external patches or data transfers can occur once the window opens.
2.  **Binary Integrity Check:** Validate checksums of the new software package against the master copy stored on the approved offline media.
3.  **Rollback Drill Simulation:** Walk through the exact steps to revert to the legacy system using only local resources. This must be timed and signed off before any installation begins.
4.  **Resource Allocation:** Assign the twelve engineers into three shifts (Prep, Install/Verify, Standby) to ensure fatigue does not compromise the critical handshake.

**Phase 2: Installation (March 10 – March 11)**
*Objective: Deploy software to the 150 sensor feeds and control interfaces without activating control loops.*
1.  **Staged Deployment:** Install software on non-critical monitoring nodes first, then progress to secondary control interfaces.
2.  **Configuration Loading:** Apply the specific calibration profiles for the 150 distinct sensor feeds.
3.  **Static Validation:** Verify file integrity and configuration syntax on all nodes. The system remains in "Maintenance Mode" with control outputs disabled.

**Phase 3: Verification and Critical Handshake (March 12)**
*Objective: Establish secure communication and transfer control authority.*
1.  **Internal Loop Testing:** Verify data flow between sensors and the new software interface while hardware controllers remain in a safe-hold state.
2.  **The Critical Handshake:** Execute the secure connection protocol between the new software and hardware controllers.
    *   *Constraint:* This is irreversible. If the handshake fails, the automatic lockdown triggers immediately.
3.  **Stability Observation:** Monitor reactor stability metrics for a defined period post-handshake before declaring the upgrade complete.

**Authorization Matrix**

**Site Director (Your) Personal Authorizations Required:**
*   **Go/No-Go for Handshake:** You must personally authorize the transition from "Static Validation" to the "Critical Handshake." This decision confirms that all pre-checks are green and the team is ready to accept the risk of automatic lockdown.
*   **Rollback Initiation:** If the handshake fails or stability metrics deviate beyond strict tolerances during the observation period, only you can authorize the emergency rollback procedure.
*   **Final Operational Release:** The formal sign-off returning the plant to full power generation status.

**Lead Engineer Oversight Responsibilities:**
*   **Technical Readiness:** Verifying binary integrity, air-gap status, and successful deployment to all 150 nodes.
*   **Shift Management:** Directing the twelve engineers through the staged deployment and ensuring adherence to the timeline.
*   **Diagnostic Analysis:** Interpreting real-time data during the internal loop testing and recommending whether conditions are safe for your Handshake authorization.
*   **Procedure Execution:** Physically executing the commands for installation and the handshake protocol upon your verbal command.

**Immediate First Step**
The immediate first step in this session is to **conduct a joint "Air-Gap and Rollback" validation drill.** Before discussing installation timelines, you and the Lead Engineer must physically verify that the offline media contains the correct, uncorrupted software build and that the team can execute the full rollback procedure within the required time limit using only local tools. If this drill fails, the upgrade cannot proceed, preventing a catastrophic scenario where the system is compromised with no viable exit strategy.
