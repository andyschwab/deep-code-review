**Decision:** Halt all non-essential testing and immediately initiate a "Freeze and Verify" protocol. The single number driving this plan is **5 days**, which is insufficient for a full parallel run; therefore, we must trade comprehensive feature testing for 100% data integrity on the critical path.

**Figures:** 210 staff × 3 countries = 630 unique payment profiles; 5 days remaining minus 1 day for final sign-off leaves 4 days for execution; 2 finance staff cannot manually verify 630 records in 4 days while doing quarterly reporting, requiring a sampling strategy of 100% high-value/high-risk + 10% random sample.

**Order of Operations**

**Phase 1: Preparation (Days 1–2)**
1.  **Data Freeze:** Lock all HR and payroll input data immediately. No changes to bank details, tax codes, or salary amounts are permitted unless legally mandated.
2.  **Mapping Validation:** The lead developer must map the four legacy provider fields to the new unified system schema. This is a technical decision the developer handles alone, provided they document any data loss or truncation risks.
3.  **Risk Sampling:** Define the "Critical 20%" of employees (highest pay, cross-border tax complexity, recent bank changes). These 42 records require manual line-item verification by finance.

**Phase 2: The Dry Run (Day 3)**
1.  **Mock Execution:** Run the payroll calculation using the frozen data. Do not transfer funds.
2.  **Variance Analysis:** Compare the mock output against the last successful run from the four legacy providers. Any variance >$0.00 triggers an immediate halt.
3.  **Finance Review:** The two finance staff review only the "Critical 20%" and the aggregate totals per country. They do not check every record.

**Phase 3: Execution (Days 4–5)**
1.  **Final Sign-off:** You (the founder) must sign off on the aggregate totals per country and the vendor contract terms regarding liability for errors. The developer cannot authorize financial liability.
2.  **Live Cutover:** Execute the real transfer.
3.  **Confirmation:** Verify bank receipt confirmations for the "Critical 20%" immediately.

**Decision Rights**
*   **Founder Sign-off Required:** Selection of the final vendor contract (specifically indemnity clauses), approval of the aggregate payment totals per country before transfer, and the "Go/No-Go" decision if variances are found in the dry run.
*   **Lead Developer Authority:** Data mapping logic, script execution, error logging, and resolving technical format mismatches between legacy and new systems. They cannot approve financial outcomes.

**Specific First Step**
**Issue a formal "Data Freeze" notice to all department heads and HR personnel effective immediately.** No payroll-related data changes can be accepted after this moment. This guarantees the dataset you are testing today is the exact dataset you will pay on the 30th. Without this freeze, testing is meaningless because the target keeps moving.

**Note:** If the legacy providers cannot export a clean, machine-readable file of the last payroll run within 4 hours, escalate this as a critical block immediately. Do not attempt to manually re-enter 210 records.
