### Strategic Sequence: Data to Live Rollout

1.  **Data Sanitization & Baseline Modeling (Weeks 1–2):**
    *   Ingest the decade of historical pickup data.
    *   Simulate the 30,000 new households into the existing map to generate a "theoretical maximum load."
    *   **Output:** A stress test report showing if 40 vehicles can physically service the expanded area within shift limits. If this fails, the plan stops here for scope reduction.

2.  **Algorithm Parameter Tuning (Weeks 3–5):**
    *   Run the routing algorithm in "offline mode" against the sanitized data.
    *   Validate integration with billing software by running dummy updates overnight to ensure no data corruption or latency spikes.

3.  **Shadow Mode Pilot (Weeks 6–10):**
    *   Drivers follow *current* static routes but carry the *new* optimized route sheets as a secondary reference.
    *   Coordinators compare actual drive times/fuel usage against the algorithm's predictions.
    *   **Goal:** Identify edge cases (e.g., narrow streets, school zones) without risking missed pickups.

4.  **Zone Definition Freeze (March 15th):**
    *   **Hard Deadline:** Finalize all geographic zone boundaries. No changes allowed after this date.
    *   Lock the master data set for the billing system integration.

5.  **Staff Training & Billing Dry-Run (Weeks 11–12):**
    *   Train drivers on new zones.
    *   Execute a full end-to-end billing dry-run using the frozen zones to verify overnight processing.

6.  **Live Rollout (May 1st):**
    *   Activate new routes.
    *   Maintain a "SWAT team" of coordinators for manual dispatch only in case of absolute emergency (vehicle breakdown), not route errors.
