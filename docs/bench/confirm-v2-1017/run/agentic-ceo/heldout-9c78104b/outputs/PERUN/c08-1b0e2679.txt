**Decision:** Freeze all feature work immediately and execute a single-threaded, gated refactor of the core order logic, starting with a deterministic performance benchmark of the current system. The one number driving this is the **48-hour window** remaining before the Monday 9:30 AM market open; any parallel experimentation or non-essential planning consumes time we do not have.

**Figures:** 50,000 transactions/minute × 3 days (remaining runway) = ~216 million transactions at risk if latency persists; 1 irreversible deploy window means 0 retries allowed.

**Session Structure & Order of Operations**

1.  **Baseline & Isolation (Hours 0–4):** Do not write new code yet. Instrument the current production-mirror environment to capture exact latency distribution (p99, not just average) under 50k TPM load. Identify the specific function or lock causing the bottleneck.
2.  **Architectural Sign-off (Hour 5):** Senior engineers propose the specific refactor pattern (e.g., lock-free queue, memory-mapped file) based on the baseline data. You must approve this approach before a single line is changed.
3.  **Implementation Sprint (Hours 6–36):** Two senior engineers pair-program the core logic rewrite. The remaining six developers build the regression test suite and the "kill switch" rollback mechanism. No other tasks exist.
4.  **Adversarial Review (Hours 37–44):** A separate senior engineer attempts to break the new logic with edge cases (partial fills, market crashes, network partitions). This is a red-team exercise, not a standard code review.
5.  **Staged Deployment Prep (Hours 45–48):** Prepare the deployment script with a feature flag to toggle the new engine instantly. Conduct a dry-run deployment on a staging cluster.

**Decision Rights: What Requires Your Approval vs. Delegation**

*   **You Must Approve (Product Lead):**

    *   **The Go/No-Go Call:** Based on the adversarial review results, you decide whether to enable the feature flag on Monday morning or revert to the legacy system.

*   **Delegate to Senior Engineers:**
