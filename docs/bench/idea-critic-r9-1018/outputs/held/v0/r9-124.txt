**Biggest Collapse Scenarios:**
1.  **Unit Economics Failure:** If the actual cost per tagged bag (hardware + transaction fees) exceeds the 5% price premium gained, the system destroys value on every shipment.
2.  **Adoption Bottleneck:** If farmers refuse the tags due to perceived surveillance or labor burden, the data chain breaks at the source, rendering the blockchain ledger useless ("garbage in, garbage out").
3.  **Regulatory Shock:** New data sovereignty laws could require local server hosting, invalidating the cloud-based blockchain architecture and spiking consulting costs.
