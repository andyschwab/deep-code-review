**Recommendation:** Do not commit the full $250,000 yet. Execute a **4-week, $25,000 capped feasibility sprint** to validate cloud hosting costs, hardware API fees, and the "5-minute session" assumption before authorizing the pilot.

**Top Three Collapse Points:**
1.  **Unit Economics Black Hole:** Without verified pricing for cloud hosting and scent-hardware APIs, the cost per user could exceed revenue, making the 12,000-user target financially unsustainable regardless of adoption.
2.  **False Engagement Baseline:** The assumption that users will spend 5 minutes mixing scents (vs. 3 minutes browsing) is unproven; if actual session time drops to 2 minutes, the projected engagement lift and retention models fail immediately.
3.  **Context Misapplication:** Replicating "ScentMingle's" UI ignores market differences; their 20,000 users in four months may rely on specific local networks or marketing channels in Bangkok that a direct UI copy cannot replicate, leading to stalled user acquisition.

**Stop-Line Metric:** If **Daily Active Users (DAU) remain below 800** after 60 days of the pilot launch, or if the **fully loaded cost per acquired user exceeds $15**, terminate the project and liquidate hardware assets.

*Note: The current plan treats unknown operational costs as zero, which invalidates the ROI calculation. The feasibility sprint must produce hard numbers on API fees before any further spend.*
