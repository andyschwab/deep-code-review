**Title:** feat(settings): Add user-controlled toggle to disable telemetry collection

**Body:**

**Problem**
Privacy-focused users and organizations operating under strict data governance policies (e.g., GDPR, internal security mandates) currently lack a mechanism to fully opt out of telemetry collection within the Northwind Editor. While aggregate usage metrics are valuable for prioritizing features, the absence of a manual override prevents adoption in regulated environments and limits the extension's accessibility to a broader developer base.

**Change**
This PR introduces a new boolean setting, `telemetry.enabled` (default: `true`), within the user settings menu. When set to `false`, the telemetry initialization routine is bypassed entirely, ensuring no usage data leaves the local environment.

**Implementation Details**
- Added a configuration flag in `settings.json`.
- Wrapped the telemetry reporting service with a conditional check against this flag.
- Updated the settings UI to expose this option with a clear description: "Allow the extension to send anonymous usage data to help improve Northwind Editor."

**Testing**
- Verified that with the flag enabled, existing telemetry behavior remains unchanged.
- Verified that with the flag disabled, no network requests are initiated by the telemetry module (validated via local network monitoring).
- Confirmed the setting persists correctly across restarts.

**Rationale**
Providing an opt-out mechanism aligns the extension with emerging privacy norms and standard practices in the open-source ecosystem, where user agency over data is increasingly expected. This change does not remove telemetry by default but empowers users who require strict data control to utilize the extension without violating their organizational policies. This expands the potential user base while maintaining the default data flow for those who wish to contribute metrics.
