### Standalone Test Case Design

To satisfy RiverFlow's reproducibility requirements without using proprietary data, you must replace the specific timestamps with a **deterministic synthetic simulation** that mimics the *timing relationship* rather than the *absolute values*.

**1. Analyze the Timing Pattern**
Instead of using the raw timestamps from Acme's logs, calculate the **delta (time difference)** between the critical events that trigger the race.
*   *Example:* If Worker A polls at `T=1000ms` and Worker B polls at `T=1002ms`, the critical factor is the `2ms` overlap, not the `1000ms` start time.
*   *Action:* Extract only these relative intervals from your logs. Discard the absolute timestamps and any payload data.

**2. Implement a Mock Clock in the Test**
RiverFlow likely uses a standard Rust async runtime (tokio/async-std). Most allow injecting a mock time source or pausing time.
*   **Strategy:** Write a test that explicitly controls the execution order of the two workers.
*   **Code Structure:**
    ```rust
    #[tokio::test]
    async fn test_concurrent_poll_race_condition() {
        // 1. Setup queue with known state
        let queue = setup_queue();

        // 2. Spawn Worker A to poll, but pause it right before the critical section
        let handle_a = tokio::spawn(async move {
            queue.poll().await;
        });

        // 3. Yield execution to ensure Worker A is waiting
        tokio::task::yield_now().await;

        // 4. Spawn Worker B to poll immediately (simulating the specific delta)
        let handle_b = tokio::spawn(async move {
            queue.poll().await;
        });

        // 5. Await both and assert that no messages were dropped
        let (res_a, res_b) = tokio::join!(handle_a, handle_b);
        assert_no_messages_dropped(res_a?, res_b?);
    }
    ```
*   **Why this works:** This test is deterministic. It forces the race condition by controlling the scheduler, removing the need for specific millisecond-precision timestamps or external logs. It proves the bug exists based on *logic*, not *data*.
