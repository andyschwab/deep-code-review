**Subject: CSV export format changes on November 9: update any spreadsheets or scripts**

Hello,

On November 9, Ledgerly's CSV exports will switch to a new format by default. If you have a spreadsheet, script, or integration that reads our exports, you may need to update it before then.

What changes:

- Dates will use ISO format (YYYY-MM-DD).
- Amounts will no longer include currency symbols.
- A new tax category column will appear immediately after the amount column. Any tool that reads columns by position will need to account for the shift.

The old format will be retired on November 30, so you have until then to finish updating anything that depends on it.

If you don't use exports in a spreadsheet or script, you don't need to do anything.

If you have questions about the change, reply to this email and we'll help.

The Ledgerly team
