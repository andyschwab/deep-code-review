### Revised Funnel Structure: Value-Consumption Model

Replace the current "Login = Active" metric with a four-stage funnel anchored on **Lead Export** as the core value action. This structure isolates superficial engagement from actual value consumption to accurately predict renewal readiness.

**1. Access (Authenticated)**
*   **Definition:** User successfully logs in.
*   **Purpose:** Measures friction in entry, not value.
*   **Status:** Necessary but insufficient. Do not count as "Active."

**2. Activation (Intent Signal)**
*   **Definition:** User executes a search with at least two filters OR views a company profile detail page.
*   **Question Answered:** Did the user attempt to find data, or did they bounce immediately after login?
*   **Threshold for "Meaningful":** Must occur within 48 hours of first login.

**3. Core Value (The North Star Input)**
*   **Definition:** User clicks "Export" (CSV, CRM push, or Email) on at least one lead record.
*   **Rationale:** In sales intelligence, data locked in the platform has zero value. Value is only realized when data enters the rep's workflow.
*   **Metric:** **Weekly Active Exporters** (users performing this action in a 7-day window).
*   **Success Criteria:** Replace the "60% weekly active login" goal with **"60% of licensed seats performing one Export per week."**

**4. Retention (Habit Formation)**
*   **Definition:** User repeats the Core Value action in at least 2 out of 4 weeks.
*   **Question Answered:** Is the tool becoming part of the weekly sales routine, or was it a one-time exploration?

### Implementation & Renewal Logic

**Event Taxonomy to Instrument Immediately**
Stop instrumenting "Page View" as a success event. Implement these three specific events to answer the renewal question:
1.  `search_executed` (Properties: `filter_count`, `result_count`) – Validates intent.
2.  `profile_viewed` (Properties: `time_on_page`, `sections_scrolled`) – Validates interest.
3.  `lead_exported` (Properties: `export_format`, `lead_count`) – **The only metric that counts toward the 60% target.**

**Renewal Readiness Matrix (April Decision)**
Categorize the 15 pilot clients based on the **Core Value** metric, not logins:
*   **Ready for Renewal:** ≥60% of licensed seats are "Weekly Active Exporters" for the last 3 consecutive weeks.
*   **At Risk (Intervention Required):** ≥40% login rate but <60% export rate. *Diagnosis:* Users see the tool but don't trust the data or don't know how to extract it. Action: Customer Success must run "Export-to-CRM" workshops.
*   **Churn Likely:** <40% export rate. *Diagnosis:* No perceived value. Action: Do not negotiate renewal; investigate product-market fit for this specific account persona.
