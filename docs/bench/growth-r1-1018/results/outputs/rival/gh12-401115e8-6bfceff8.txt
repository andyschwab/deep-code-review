# Framework for Redefining SketchSync's Activation Event

To pinpoint the true moment of value realization, your user research must isolate whether activation is driven by the **mechanical act of inviting** or the **experiential act of collaborating**. The current "board created" metric is a vanity metric because it measures output, not outcome. The low Day-3 retention (15%) confirms that creating a board does not equate to realizing value.

Use the following logical framework to guide your qualitative interviews and redefine the activation event:

### 1. Distinguish Intent from Realization
The core hypothesis is that value in a collaborative tool is network-dependent. You must determine if the user feels value *in anticipation* of collaboration (upon sending an invite) or only *during* the collaboration (real-time interaction).
*   **Investigation Focus:** Ask users who created a board but never invited anyone why they stopped. Conversely, ask users who invited someone but never collaborated if they felt the tool was successful.
*   **Logical Filter:** If users report feeling "stuck" or "unsuccessful" after inviting but before collaborating, the activation event must require the second user's presence. If they feel satisfied simply having sent the link, the "invite sent" event is sufficient.

### 2. Identify the "Aha!" Moment Specificity
"Collaborating" is too broad. You must identify the specific micro-action within a session that triggers value.
*   **Investigation Focus:** In interviews, walk users through their first successful session. Pinpoint the exact second they thought, "This works for my team."
*   **Key Variables to Isolate:**
    *   Was it seeing the cursor move?
    *   Was it the first comment added by another user?
    *   Was it the completion of a joint task (e.g., finishing a diagram together)?
*   **Logical Filter:** The activation event should be the earliest repeatable action that correlates with long-term retention. If "cursor visibility" is the trigger, tracking "second user joined" is too late; if "joint task completion" is the trigger, "second user joined" is too early.

### 3. Validate the Time-to-Value Window
Your current data uses a 24-hour window for creation but measures retention at Day 3. The definition of activation must align with the speed at which value is delivered.
*   **Investigation Focus:** Determine the expected timeframe for the "second person" to arrive. Is the value realization immediate (synchronous) or delayed (asynchronous)?
*   **Logical Filter:** If the value is synchronous, the activation event must occur within a single session involving two users. If asynchronous, the event might be "first response received," regardless of time elapsed. The definition changes the onboarding flow: synchronous requires driving immediate invites; asynchronous requires nurturing the inviter while waiting.

### 4. Segment by User Role and Context
The "value moment" may differ based on who is signing up (the initiator vs. the invitee) and their use case (brainstorming vs. structured planning).
*   **Investigation Focus:** Compare the retention drivers for users who started the board versus those who joined via a link.
*   **Logical Filter:** If initiators retain only when invitees *act*, the activation event for the initiator is "invitee action." If invitees retain simply by participating, their activation event is different. Do not force a single event if the roles have fundamentally different value propositions, but prioritize the *initiator's* activation for onboarding optimization since they control the viral loop.

### Recommendation for Research Design
Design your interview script to retroactively reconstruct the user's emotional state at three specific checkpoints:
1.  Immediately after creating the board.
2.  Immediately after sending the first invite.
3.  Immediately after the first collaborative interaction.

The checkpoint where the user transitions from "evaluating" to "relying" on the tool is your true activation event. Redefine your tracking to match this specific behavioral threshold, not just the setup of the environment.

*Note: Ensure your qualitative findings are later validated against cohort retention data to confirm the new event correlates with Day-30 retention, not just Day-3.*
