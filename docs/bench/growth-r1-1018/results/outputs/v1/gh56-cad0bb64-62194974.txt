**Recommended North Star Metric:** **Weekly Active Planners Completing a Verified Reporting Cycle.**

This metric counts the number of unique city planners who, within a seven-day window, not only log in but successfully generate, export, or submit a final report (or equivalent decision artifact) using GreenCity data that is marked as "verified" or "used" in their workflow.

**Why this over vanity metrics:**
Login frequency (currently 2x/week) is a vanity metric; it measures software access, not value delivery. A planner can log in, find the data too latent or confusing, and leave without achieving their goal. Your assumption—that the tool must reduce reporting time by 30%—implies the *outcome* (completed reporting) is what matters, not the *attempt* (login). By shifting focus to "Completed Reporting Cycles," you align the technical team (who must fix latency and insight gaps to enable completion) with civic stakeholders (who need finished reports for mayors). If this metric rises, it proves the 30% time-saving hypothesis is being realized; if it stays flat while logins rise, you have confirmed a product leak where users try but fail to derive value.

**Validation Strategy Against Data Gaps:**
You currently cannot measure this because your instrumentation likely stops at "Page View" or "Session Start." To validate this metric before June without fabricating benchmarks:

1.  **Instrument the "Finish Line" Immediately:** Define the specific user action that constitutes a "completed report" (e.g., clicking "Export PDF," hitting "Submit to Council," or toggling a "Report Generated" status). Instrument this single event. Do not track "everything"; track only this completion signal.
2.  **Establish the Baseline (UNVERIFIED until instrumented):** Do not estimate the current completion rate. Until the event is live, the value is `UNVERIFIED`. Once live, measure the ratio: *(Weekly Completed Cycles) / (Weekly Active Logins)*. This is your activation/retention leak diagnostic.
3.  **Qualitative Seam Check:** Since you have only three cities, pair this quantitative metric with a weekly manual check: ask the 5–10 most active planners if the generated report actually replaced their previous manual workflow. The metric is only valid if the user confirms it saved them time.
