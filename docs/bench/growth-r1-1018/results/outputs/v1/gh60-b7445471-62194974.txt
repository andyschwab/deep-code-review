### Revised Funnel Structure: Value-Consumption Model

Replace the current "Login = Active" definition with a four-stage funnel anchored on **Lead Export** as the core value action. This structure isolates superficial engagement from actual value consumption to accurately predict renewal readiness.

**1. Access (Authenticated)**
*   **Definition:** User successfully logs in.
*   **Purpose:** Measures frictionless entry only; **not** an indicator of value.
*   **Status:** Necessary but insufficient. High volume here with drop-off later indicates a "login trap" where users enter but find no utility.

**2. Intent (Search Executed)**
*   **Definition:** User submits a query with at least two filters (e.g., industry + role) resulting in a results page load.
*   **Purpose:** Validates that the user is attempting to solve a specific sales problem rather than browsing aimlessly.
*   **Threshold:** A session without a search is considered a "bounce," regardless of duration.

**3. Evaluation (Profile Viewed)**
*   **Definition:** User clicks into a specific lead profile and spends >15 seconds on the detail view.
*   **Purpose:** Confirms the user is assessing data quality. This filters out users who run searches but reject the results immediately.

**4. Value Realization (Lead Exported) — *The North Star Event***
*   **Definition:** User clicks "Export" or "Add to CRM" for at least one lead profile.
*   **Purpose:** This is the only event that constitutes **Weekly Active Usage (WAU)** for your 60% success criterion.
*   **Rationale:** In B2B sales intelligence, value is not consumed until the data leaves the platform to be used in an outreach workflow. Without an export, the pilot has delivered zero ROI.

**Revised Success Metric Calculation**
*   **Old Metric:** (Users with ≥1 Login) / (Total Seats)
*   **New Metric:** (Users with ≥1 **Lead Export** in 7 days) / (Total Seats)
*   **Application:** An account is "Renewal Ready" only if ≥60% of its assigned seats hit the **Value Realization** stage weekly for three consecutive weeks leading up to April.

**Immediate Instrumentation Requirements**

Any metric derived without these specific events is `UNVERIFIED`.
