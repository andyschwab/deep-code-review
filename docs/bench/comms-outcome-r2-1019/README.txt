Method (PREREGISTERED.md, AMENDMENT.md; hashes in SHA256-frozen.txt and ledger.jsonl)
- Guard: r1's regex flags numeric tokens and weekdays in the message absent from the notes. GLM-5.2 (prompts/fab_judge.txt), blind to the arm, sees the notes, the message and the flagged tokens and labels each supported (same figure reformatted, correct arithmetic, count, list numbering, implied period, a statement about the message) or fabricated. A message is really fabricated when any token is. Scenario rate = share of its 3 samples.
- Validation (before freezing; make_sample.py, sample.json, labels.json, validation_bar.txt, validation.jsonl): every V0 and E4 flagged token of r1 held-out plus 14 random from each of humanizer and no skill, labelled by hand before any judge call, split at random into dev (51) and test (40). One prompt edit on dev (a JSON-format fault); test judged once against a bar written first (agreement >= 0.90, recall >= 0.75).
- Arms: V0 (v1.2.4), E4 (frozen r1 text, no further tuning), humanizer v3.1.0 (descriptive). Scenarios: 80 valid of 105 unused (kind, domain) pairs (decision 18, status 20, pr 15, exec 15, incident 12), r1's brief and validity checks, written after the freeze and hashed before any arm call; bench_check clean. Generator Qwen3.5-397B-A17B, readers GLM-5.1 and gpt-oss_120b, grader GLM-5.2, paired percentile bootstrap, 10,000 resamples, seed 1. Run once; missing_grades=0 and no unlabelled figure for V0 and E4.
- Keep rule: accuracy CI lower bound > 0 (met); real-fab upper bound <= +0.02 (0.033, failed); words <= 1.25 x V0 (met); judge complete (met). Other r1 conditions (dropped rate 0.796 against 0.833, lower; each reader >= 0) are reported, not gating.

Known limits
- One judge model and one model labeller; recall rests on 8 test cases. Gray cases flip (9% for an actual 9.2% yield gain was labelled supported by hand, fabricated by the judge).
- One generator, two reader families, model-written scenarios; the skill is written for Claude and run here on another model. The regex only inspects numbers and weekdays, so a wrong name or a claim without a figure is invisible to this guard.
- The 0.02 margin is the owner's; at n=80 it is stricter than the interval's width, so even a true tie usually fails it (stated in the preregistration).
- scripts/rival_eval.py (chat client, bootstrap, GEN_TASK) is shared and not snapshotted; r1's bench.py, fixed.py, fixed2.py and audit.py are reused in place and hashed here.
