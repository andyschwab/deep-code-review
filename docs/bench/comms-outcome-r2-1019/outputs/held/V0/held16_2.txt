This PR replaces the ultrasonic ranging algorithm with a vision-based one on M12 sensor nodes to address the 27% underreporting seen in last month's pilot. The diff adds ~9k lines, updates the calibration table to 38 entries, and modifies the power profile.

We must choose between two implementation approaches:
