This PR swaps the ultrasonic ranging algorithm for a vision-based one on M12 sensor nodes to address the 27% underreporting seen in last month's pilot. The diff adds ~9k lines, updates the calibration table to 38 entries, and modifies the power profile.

Two implementation approaches are available:

*   **Approach A (Edge Inference):** Runs inference on the node.
    *   **Power:** Projects 11% faster battery drain.
    *   **Accuracy:** 1.8% false-positive rate.
    *   **Compute:** Reduces central compute load.
*   **Approach B (Gateway Offload):** Offloads inference to the gateway.
    *   **Power:** Maintains the current 14-month battery target.
    *   **Accuracy:** 1.2% false-positive rate.
    *   **Latency:** Adds 0.2s latency.

The author leans toward Approach B to preserve battery life, but a final decision is required to proceed. Integration tests for both methods are complete.
