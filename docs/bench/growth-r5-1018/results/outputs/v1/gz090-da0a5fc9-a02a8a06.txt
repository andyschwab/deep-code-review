### Diagnostic Event Taxonomy: 'Data Science Basics' Module 3

To resolve whether learners are failing tests, skipping content, or dropping off, instrument the following four events. Each event includes the specific properties required to answer your open questions and trigger a decision.

**1. `video_section_abandoned`**
*   **Question Answered:** Are learners skipping the setup tutorials entirely?
*   **Properties:** `module_id` (fixed: "DS_Basics_M3"), `section_id`, `completion_percentage`, `last_timestamp`.
*   **Reading Rule:** If >40% of users who started Module 3 have `completion_percentage` < 20% for the "Environment Setup" video section, the bottleneck is **content avoidance**.
*   **Action:** Move setup instructions to a pre-course checklist or provide a cloud-based alternative immediately; do not wait for code data.

**2. `sandbox_launch_attempt`**
*   **Question Answered:** Are users dropping off before attempting the exercise due to setup friction?
*   **Properties:** `user_id` (pseudonymous), `launch_status` (success/fail/timeout), `os_type`, `time_to_launch_ms`.
*   **Reading Rule:** If the ratio of `enrolled_users` to `sandbox_launch_attempt` is < 50%, or if `launch_status` = "fail/timeout" exceeds 15%, the bottleneck is **environment friction**.
*   **Action:** Engineering to prioritize the one-click cloud sandbox; Instructional Design to pause complex local setup requirements.

**3. `code_submission_result`**
*   **Question Answered:** Are learners failing the automated tests after attempting the work?
*   **Properties:** `submission_id`, `test_case_pass_rate` (0.0–1.0), `error_category` (syntax, logic, environment_missing), `attempt_number`.
*   **Reading Rule:** If `sandbox_launch_attempt` is high but `final_project_submission` remains low, check `test_case_pass_rate`. If the median pass rate is < 0.5 after 3 attempts, the bottleneck is **exercise difficulty**.
*   **Action:** Simplify test cases or provide intermediate scaffolding hints; do not change the setup guide.

**4. `forum_search_zero_result`**
*   **Question Answered:** Are users looking for help but failing to find it?
*   **Properties:** `query_text`, `module_context`, `result_count`.
*   **Reading Rule:** High volume of queries containing "setup", "install", or "error" with `result_count` = 0 indicates **documentation gaps**.
*   **Action:** Create targeted FAQ entries or pinned forum threads for the top 3 zero-result queries within 48 hours.

**Analysis Plan for Stakeholders**
*   **Instructional Design Team:** Focus on Event 1 and Event 4. If video abandonment is low but search failures are high, the content exists but is hard to find. If abandonment is high, the content format is the barrier.
*   **Engineering Lead:** Focus on Event 2 and Event 3. If launch failures correlate with specific `os_type`, the local environment requirement is the blocker. If launches succeed but submissions fail with `environment_missing` errors, the sandbox integration is leaking state.
