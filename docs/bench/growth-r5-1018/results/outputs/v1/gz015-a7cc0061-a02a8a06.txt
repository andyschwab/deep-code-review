**Diagnostic Plan: 'Industry Insights' Engagement Drop**
**Audience:** European Regional Director | **Decision Date:** Next Tuesday

**1. Recompute the Baseline & Define the Core Question**
The drop from 8.0 to 5.5 minutes (−31%) is significant, but session duration is a vanity metric if it doesn't reflect value. The core question is not "why is time down?" but "did we displace high-value actions?"
*   **Action:** Calculate **Revenue/Retention per Session** for the pre-launch (Sept 1–11) vs. post-launch (Sept 12–today) periods. If revenue/retention is flat despite lower duration, the feature may have improved efficiency (a win). If both dropped, we have a retention leak.
*   **Metric Status:** Current CTR (1.2%) is `UNVERIFIED` as a failure without a baseline. Compare against the CTR of the previous news module or the organic feed average.

**2. Segmentation Strategy (The "Who" and "Where")**
Break down the data by these specific cuts to isolate the friction point. Each cut dictates a specific action:
*   **Segment A: Paris vs. Non-Paris Users.**
    *   *Hypothesis:* Content relevance is geo-specific.
    *   *Reading Rule:* If the drop is isolated to Paris, the curation algorithm or content source is flawed. **Action:** Switch Paris feed to global trending temporarily. If uniform, the layout is the culprit.
*   **Segment B: New (<30 days) vs. Established Users.**
    *   *Hypothesis:* The feature confuses onboarding.
    *   *Reading Rule:* If new users drop off immediately after seeing the feed, the layout obscures the "core action" (connecting/messaging). **Action:** Hide the feed for new users for 7 days.
*   **Segment C: Cannibalization Check (Messaging Clicks).**
    *   *Hypothesis:* Users click "Insights" instead of "Messages."
    *   *Reading Rule:* Correlate session-level events. Did sessions with an "Insights View" have zero "Message Open" events? **Action:** If yes, move the feed below the messaging fold or reduce its visual weight.

**3. Event Taxonomy: Instrument Only What Answers the Question**
Do not track everything. Implement these three specific events immediately to answer the hypotheses above:
1.  `feed_scroll_depth` (Properties: `user_segment`, `content_category`): Answers "Do they find *any* content relevant?"
    *   *Threshold:* If >60% of users scroll <20%, the content is irrelevant.
2.  `feed_exit_to_home` (Properties: `time_on_feed`): Answers "Is the layout confusing?"
    *   *Threshold:* High immediate exits suggest UI confusion.
3.  `core_action_displaced` (Properties: `session_has_insights_view`, `session_has_message_click`): Answers "Cannibalization."
    *   *Threshold:* Negative correlation between insights views and message clicks confirms cannibalization.

**4. Decision Matrix for Tuesday's Meeting**
Present the findings using this table to force a binary decision:

| Finding | Interpretation | Recommended Action |
| :--- | :--- | :--- |
| **Retention/Revenue Flat** despite time drop | Feature improved efficiency; duration was bloated. | **Ship:** Optimize for speed, ignore duration metric. |
| **Paris-only drop** + Low `feed_scroll_depth` | Content relevance failure in local market. | **Iterate:** Replace content source; keep layout. |
| **Uniform drop** + High `core_action_displaced` | Layout cannibalizing high-value actions. | **Rollback/Redesign:** Move feed below the fold immediately. |
| **New User drop** + High `feed_exit_to_home` | Onboarding friction. | **Iterate:** Gate feature for users >7 days old. |
