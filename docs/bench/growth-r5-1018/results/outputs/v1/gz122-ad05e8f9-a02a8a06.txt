### Instrumentation Plan: NewsNile Social Feed (Code Freeze: Sept 28)

**North Star Metric:** Weekly Active Users completing a "Social Loop" (Read → Comment/Share → Return within 48h).
*Reject vanity metrics like total comments or raw session time; they rise with noise but not value.*

**Prioritized Event Taxonomy**
Instrument only these events to answer specific questions for the November board decision. Every event must include `user_id` (pseudonymous), `session_id`, and `content_category`.

| Priority | Event Name | Properties | Question Answered |
| :--- | :--- | :--- | : |
| **P0** | `social_action_attempt` | `type` (comment/share), `article_id`, `success` (bool) | Is the core social function working technically and behaviorally? |
| **P0** | `session_end_reason` | `last_action`, `duration_sec`, `return_via_push` (bool) | Does social usage replace or complement push-driven traffic? |
| **P1** | `push_notification_click` | `campaign_id`, `landing_page` (feed vs. article), `time_since_send` | **Guardrail:** Is the 8% CTR cannibalized by organic feed usage? |
| **P1** | `content_consumption_depth` | `articles_read_count`, `source` (feed vs. list vs. push) | Does the feed increase depth beyond the current 40% baseline? |
| **P2** | `scroll_depth_feed` | `percentage`, `time_spent_sec` | (Only if P0/P1 show ambiguity) Are users engaging or just scrolling mindlessly? |

**Isolating Impact: The Experiment Design**
Do not rely on "before vs. after" comparisons; regular content updates will confound the data.
1.  **Holdout Group:** Route 10% of eligible users to the *old* interface (no social feed) for 4 weeks post-launch (Oct 5–Nov 2).
2.  **Primary Read:** Compare the "Social Loop" rate and Push CTR between the Test (90%) and Holdout (10%) groups.
3.  **Guardrail Rule:** If Push CTR in the Test group drops >15% relative to Holdout *and* "Social Loop" retention is <5%, the feature creates noise, not community.

**This Week's Steps (Before Sept 28)**
1.  **Define Schema:** Finalize the JSON schema for the 5 events above with the Alexandria team; explicitly exclude generic "scroll" events unless P0/P1 data is inconclusive.
2.  **Configure Holdout:** Implement the 10% feature flag logic to ensure a clean control group exists from Day 1 of launch.
3.  **Baseline Query:** Run a query on current data to establish the exact baseline correlation between "articles read" and "push clicks" to detect shift magnitude later.

*Note: Do not fabricate a "good" retention target; compare the November results strictly against the holdout group's performance. If the holdout data is corrupted, the November decision must be "Extend Test," not "Go."*
