# PixelQuest South Korea Soft-Launch: Metric Framework & Instrumentation Plan

**Audience:** Founding Team & Local Publishing Partner
**Context:** Pre-launch (April 5), Beta Baseline: 18m session, 25% D1 retention.

### 1. The North Star Metric
**Weekly Active Users (WAU) completing a "Stable Guild" action.**
*Definition:* A user who logs in ≥3 times/week AND is a member of a guild with ≥3 active members for 7 consecutive days.
*Rationale:* Session length (18m) is a vanity metric if the user leaves forever. Retention (25%) is the leak. Value in social gaming is not "playing," it is "belonging." This metric rises only when users derive social value, directly testing your hypothesis that guilds drive longevity.

### 2. The Top Five Metrics (AARRR, Read Bottom-Up)
Do not track acquisition until retention stabilizes. Read these in order:

1.  **Retention (The Leak):** **D7 Retention of "Guilded" vs. "Unguilded" users.**
    *   *Question:* Does joining a guild actually fix the 25% D1 drop-off?
    *   *Action:* If the gap is <10%, the guild hypothesis is false; pivot core loop. If >20%, force guild onboarding.
2.  **Activation (The Aha Moment):** **% of New Users joining a guild within 24 hours.**
    *   *Question:* Is the path to the "Stable Guild" state frictionless?
    *   *Action:* If <40%, redesign the first-session flow to prioritize guild creation over tutorial completion.
3.  **Engagement (The Habit):** **Weekly Guild Activity Rate.**
    *   *Definition:* % of guild members contributing (chat, quest, gift) ≥2 times/week.
    *   *Question:* Are guilds alive or ghost towns?
    *   *Action:* Low activity indicates "zombie guilds"; implement re-engagement triggers or guild dissolution mechanics.
4.  **Monetization (The Sustainability):** **ARPDAU (Average Revenue Per Daily Active User) by Guild Status.**
    *   *Decision:* Track from Day 1, but do not optimize for it yet. Compare paying rates between guilded/unguilded users to validate if social pressure drives spend.
5.  **Acquisition (The Scale):** **Organic Install Rate via Referral Codes.**
    *   *Question:* Are users inviting friends (critical for Korea's social market)?
    *   *Action:* Only scale paid ads if Referral Rate > 15%.

### 3. Immediate Instrumentation Plan
Stop tracking "session length" as a primary KPI. Implement these specific events immediately:

| Event Name | Properties | Question Answered |
| :--- | :--- | :--- |
| `guild_created` | `creator_id`, `invite_method`, `initial_size` | How are successful guilds formed? |
| `guild_joined` | `user_id`, `time_since_install`, `guild_id` | How fast do users reach the "Aha" moment? |
| `guild_action` | `action_type` (chat/quest/gift), `guild_id` | What specific behaviors correlate to retention? |
| `session_end` | `duration`, `was_guilded` (bool) | Replace raw session length with segmented value. |

**Vanity vs. Actionable:**
*   **Vanity:** Total Downloads, Cumulative Registrations, Average Session Length (aggregate). These rise even if the product fails.
*   **Actionable:** D7 Retention by Cohort, Guild Formation Rate, Referral Conversion. These diagnose *why* users stay or leave.

### 4. Monetization Strategy
**Track from Day 1, Optimize later.**
Do not gate revenue tracking. You must calculate the break-even LTV (Lifetime Value) early to determine if the 25% retention is financially viable. However, do not introduce friction (paywalls) that blocks guild formation during the soft launch. Use the data to see if "Guilded" users monetize higher; if yes, monetization is a downstream effect of social success.

### 5. This-Week Steps
1.  **Define the Schema:** Finalize the `guild_created` and `guild_joined` event properties by April 2nd; ensure the user ID is persistent across sessions to measure D7 retention accurately.
2.  **Set the Tripwire:** If D7 retention for "Guilded" users is <30% by April 20th, pause all paid acquisition and dedicate 100% of engineering to the onboarding funnel.
3.  **Baseline the Gap:** Run a query on beta data immediately (if IDs exist) or wait 48 hours post-launch to compare D1 retention of users who joined a guild vs. those who didn't.
