### Diagnostic Framework: SkillForge Engagement Decay
**Audience:** Learning & Development Directors | **Workshop Date:** April 10th | **Goal:** Isolate retention leak before acquiring new users.

**1. The North Star & Input Metrics**
*   **North Star:** *Weekly Active Learners completing a core module.* (Reject "total signups" or "content views" as vanity; they rise while value stagnates).
*   **Input Metrics:** Module 1→2 transition rate, time-to-first-completion, and manager-assignment latency.

**2. Event Taxonomy: Measuring the Drop-Off**
Instrument only these events to answer specific questions. Do not track "everything."
*   `module_started` (Property: `module_id`, `user_team_id`): *Are users even starting?*
*   `module_completed` (Property: `module_id`, `duration_seconds`): *Where exactly do they stop?*
*   `notification_clicked` (Property: `channel`, `campaign_type`): *Is fatigue ignoring valid prompts?*
*   `manager_assigned_task` (Property: `team_id`, `timestamp`): *Is there a lag between assignment and start?*

**3. Hypotheses to Test (3-Week Sprint)**
*   **H1 (Content Relevance):** Drop-off is highest after Module 1 regardless of team. *Test:* Compare completion rates of new modules vs. legacy modules for the same cohort. If both drop equally, content is not the primary driver.
*   **H2 (Notification Fatigue):** Users who receive >3 reminders/week have lower click-through rates than those receiving 1. *Test:* Segment users by notification volume over the last 30 days and correlate with `module_started`.
*   **H3 (Manager Involvement):** Teams with active manager logins have 20% higher retention than those without. *Test:* Cohort analysis comparing `manager_assigned_task` frequency against learner `module_completed` rates.
*   **H4 (Usability/Remote Context):** Drop-off spikes on mobile or during specific EU time zones. *Test:* Segment `module_completed` by device type and start-time hour.

**4. Unknown Variables: Manager Involvement**
*   **The Assignment Gap:** Time delta between content publication and manager assignment to learners. A long lag kills momentum.
*   **Manager Modeling:** Whether managers themselves complete the training. If leaders don't participate, remote teams rarely engage.
*   **Feedback Loop:** Existence of a `manager_feedback_submitted` event. Without this, L&D cannot distinguish between "didn't see it" and "saw it but deemed irrelevant."

**5. This-Week Steps**
1.  **Query Retention Cohorts:** Run a query grouping users by `team_id` to calculate the Module 1→2 transition rate for January vs. March. If the drop is uniform across teams, the issue is platform/content; if isolated, it is team-specific (manager-led).
2.  **Define the "Activation" Event:** Agree that "Activation" = *completing the first module within 48 hours of assignment*. Measure this rate for the last 50 teams.
3.  **Prepare the Workshop Visual:** Plot a funnel showing `assigned` → `started` → `completed`. Highlight the single largest percentage drop. This is the only metric that matters for the April 10th decision.

*Note: All benchmarks must be calculated against SkillForge's own January baseline (45%); do not compare to external industry averages which are unavailable here. If manager login data is missing, mark the manager hypothesis as `UNVERIFIED` until instrumentation is added.*
