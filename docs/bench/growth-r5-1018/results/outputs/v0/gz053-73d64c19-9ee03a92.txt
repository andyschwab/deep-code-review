### Investigation Plan: Interactive Ad Impact on Retention and Revenue

**Objective:** Determine if the 25% drop in average session duration (55m → 41m) represents total churn (subscription cancellation) or content avoidance (skipping/early exit), and calculate if the ad revenue lift offsets the loss in viewing volume.

#### 1. Diagnose the Drop: Churn vs. Avoidance
Use your existing **exit point** and **ad click** data to segment the post-Feb 10th drop. Do not assume the cause; verify it against the user's own baseline.

*   **Metric A: Post-Ad Exit Rate.** Calculate the percentage of sessions ending within 2 minutes of an interactive ad impression.
    *   *Reading Rule:* If this rate spiked significantly compared to the pre-Feb 10th baseline for standard ads, users are actively avoiding the format (content avoidance).
*   **Metric B: 7-Day Return Cohort.** Group users who had a session on Feb 10–17. Track if they returned in the subsequent 7 days.
    *   *Reading Rule:* If return rates match pre-change cohorts, the drop is **avoidance** (they come back but watch less per session). If return rates dropped, the drop is **churn** (they left the platform).
    *   *Constraint:* Since cross-device identity is `UNVERIFIED` without a stable user ID merge, state this limitation. If you cannot link devices, you cannot distinguish a user switching devices from a user leaving. Flag this as a data gap requiring identity resolution before finalizing churn claims.

#### 2. Calculate the Trade-off: Revenue vs. Volume
The advertising sales director needs to know if the higher yield per ad compensates for fewer minutes watched.

*   **Formula:** `Net Revenue Impact = (New Ad RPM × New Total Impressions) - (Old Ad RPM × Old Total Impressions)`
*   **Input Data Needed:**
    *   Click-through rate (CTR) of the new interactive format vs. old format.
    *   Cost Per Click (CPC) or CPM uplift provided by sales.
    *   Total impression count change (derived from the drop in session duration × frequency).
*   **Decision Threshold:** If `Net Revenue Impact` is positive but **Metric B** (Return Cohort) shows a decline >5% vs. baseline, the gain is short-term and risks long-term licensing value (cost per view rises as total views fall).

#### 3. Immediate Actions (This Week)
1.  **Run the Post-Ad Exit Query:** Filter logs for sessions ending <2 mins after an interactive ad. Compare the % to the Jan 20–Feb 9 baseline.
    *   *Action:* If the rate is >2x baseline, immediately reduce frequency from every 15 mins to every 25 mins for a 48-hour canary test.
2.  **Cohort Return Check:** Pull the 7-day retention curve for users active Feb 10–12.
    *   *Action:* If retention is flat, reassure content acquisition that licensing costs per view are stable despite lower session length. If retention dips, pause the rollout on high-value content titles.
3.  **Identity Gap Note:** Document that cross-device churn is `UNVERIFIED`. Do not report a definitive "churn rate" to the board until user IDs are unified; report "single-device churn" only.

**Verdict Logic:**
*   **Ship/Keep:** If revenue lift >15% AND 7-day return cohort is within 2% of baseline.
*   **Adjust:** If revenue lift <10% OR 7-day return cohort drops >5%.
*   **Stop:** If 7-day return cohort drops >10% regardless of revenue lift (long-term LTV destruction).

*Note: All benchmarks above refer strictly to StreamFlow's pre-Feb 10th historical data. No external industry retention rates are applied.*
*Cross-device behavior remains `UNVERIFIED` until a stable pseudonymous user ID is implemented across platforms.*
