### Diagnostic Event Plan: 'Data Science Basics' Module 3 Bottleneck

**Objective:** Isolate whether the 22% completion drop is caused by content disengagement (skipping videos), technical failure (setup errors), or abandonment before the attempt.

**Required Event Taxonomy**
Instrument only the following events to answer specific diagnostic questions. Do not track "everything"; these four events directly address the open questions.

| Event Name | Question Answered | Required Properties |
| :--- | :--- | :--- |
| `video_section_complete` | Are learners skipping the setup tutorial video? | `module_id`, `section_id` (specifically the "Local Env Setup" segment), `percent_watched`, `user_id` |
| `code_submit_attempt` | Are users attempting the exercise but failing tests? | `module_id`, `attempt_number`, `test_results_pass_count`, `test_results_fail_count`, `user_id` |
| `sandbox_error_log` | Is the local environment setup failing technically? | `module_id`, `error_type` (e.g., "dependency_missing", "path_error"), `timestamp`, `user_id` |
| `forum_search_query` | Are users actively searching for help before dropping? | `module_id`, `query_terms`, `result_click_count`, `user_id` |

**Analysis Logic & Decision Rules**
Cross-reference these events against the cohort of 5,000 enrolled users to segment the 3,800 who did not submit the final project.

1.  **If `video_section_complete` is low (<40% for the setup segment):**
    *   **Diagnosis:** Content skip or visibility issue.
    *   **Action:** Instructional Design to move the setup video to a mandatory gate before the exercise unlocks. Do not change the exercise yet.

2.  **If `sandbox_error_log` is high (>30% of attempts) with "dependency" or "path" errors:**
    *   **Diagnosis:** Environment complexity is the blocker (confirms hypothesis).
    *   **Action:** Engineering to prioritize a browser-based sandbox alternative or provide a one-click Docker container. Simplify requirements immediately.

3.  **If `code_submit_attempt` is high but `test_results_pass_count` is 0 across multiple attempts:**
    *   **Diagnosis:** Users are trying but the tests are unclear or the bar is too high.
    *   **Action:** Instructional Design to review test feedback messages for clarity; consider adding intermediate scaffolding steps.

4.  **If `forum_search_query` spikes with "setup" or "install" terms, followed by zero `code_submit_attempt`:**
    *   **Diagnosis:** Users are stuck and giving up before the first attempt.
    *   **Action:** Create a targeted "Setup Troubleshooting" pinned post or email trigger for users who hit this search pattern.

**Baseline Comparison**
Compare the rates of these four events for the March 1st cohort against the average of previous cohorts. The specific delta in *one* of these events will identify the root cause. Without this comparison, the absolute numbers are `UNVERIFIED` as indicators of a new problem.
