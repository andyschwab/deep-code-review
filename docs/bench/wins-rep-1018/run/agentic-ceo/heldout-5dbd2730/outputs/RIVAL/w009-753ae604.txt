*   **Wave A (Hours 6–24):** If the pilot succeeds, deploy to 15 branches in the same region.
*   **Wave B (Hours 24–42):** Deploy to 25 branches in adjacent regions.
*   **Wave C (Hours 42–48):** Final 17 branches, prioritizing high-volume urban centers only if earlier waves show zero latency issues.
