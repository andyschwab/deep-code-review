### Fall Detection Sensor Deployment Workflow

**1. Pilot Testing vs. Full-Scale Deployment Sequence**
Do not proceed to full deployment until the pilot phase validates the calibration model.
*   **Phase A: Controlled Pilot (Days 1–5):** Select one floor in the oldest facility (highest interference risk) and one floor in the newest facility. Install sensors in 20 rooms total (10 per site). Do not activate alerting to staff yet; run in "logging only" mode.
*   **Phase B: Data-Driven Calibration (Days 6–10):** Analyze logged data against known fall simulations and normal movement patterns. Adjust sensitivity thresholds centrally.
*   **Phase C: Live Pilot (Days 11–15):** Activate alerts for the pilot rooms only. Monitor false positive/negative rates with staff feedback.
*   **Phase D: Staged Rollout (Days 16–30):** If Phase C metrics meet safety standards, deploy to remaining facilities in batches of three, utilizing the ten technicians as roving calibration teams rather than static installers.

**2. Calibration Parameters Requiring Executive Sign-Off**
You must personally approve the following thresholds before the "Live Pilot" begins. These are irreversible without manual unit intervention:
*   **Acceleration G-Force Threshold:** The specific gravity spike defining a "fall" versus a "dropped object" or "rapid sit."
*   **Inactivity Timer Duration:** The time elapsed after an impact event before an alert is triggered (balancing immediate response vs. self-recovery).
*   **Signal Noise Floor:** The baseline interference level accepted as "normal" before the system flags a sensor malfunction.
*   **False Positive Tolerance Rate:** The maximum percentage of non-event alerts acceptable per 1,000 hours of operation (e.g., <0.5%).

**3. Logistical Arrangements for Technicians**
Technicians can self-organize the following without executive oversight:
*   **Physical Mounting Schedule:** Sequencing room entry based on resident care schedules to minimize disruption.
*   **Hardware Kitting:** Pre-packaging sensors, mounts, and batteries for daily quotas.
*   **Local Network Pairing:** The immediate pairing of device IDs to room numbers within the local gateway.
*   **Travel Routing:** Optimizing routes between the fifteen facilities to maximize daily installation counts.

**4. Immediate First Steps: Wireless Mesh Stability Verification**
Before shipping any hardware to the oldest building, execute these verification steps immediately:
*   **Step 1:** Deploy two portable Wi-Fi spectrum analyzers to the oldest building's target floor.
*   **Step 2:** Conduct a 24-hour passive scan during peak activity hours (morning rounds, meal times, shift changes) to map interference from existing medical equipment and legacy Wi-Fi.
*   **Step 3:** Perform a "dead zone" walk-through using a test mesh node to identify areas where signal strength drops below the required -85dBm threshold.
*   **Step 4:** Generate a heat map of signal integrity. If coverage is below 98%, plan for additional mesh repeaters before sensor installation begins.

**Note:** The strict deadline requires that the "Data-Driven Calibration" phase be completed within 5 days to allow sufficient time for the staged rollout. Failure to validate the mesh network in Step 4 will invalidate all subsequent calibration efforts.
