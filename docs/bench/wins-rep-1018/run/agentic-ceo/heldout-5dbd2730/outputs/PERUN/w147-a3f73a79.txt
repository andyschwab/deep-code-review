### Strategic Choices (Owner Only)
You must decide the **communication protocol and liability shield**. The technical team cannot negotiate business cycles.
1.  **Notification Escalation:** Authorize direct C-level outreach to the five banks immediately, bypassing standard developer channels. You must decide if we offer a formal "extension waiver" for partners who prove active migration but miss the date.

3.  **Incentive vs. Penalty:** Decide if we subsidize their migration costs (carrot) or enforce strict SLA penalties for continued v2 usage after June 1st (stick).

### Technical Execution (Team Only)
The integration team handles the **mechanism of degradation**, not the policy.

2.  **Header Injection:** Implement a `Deprecation: true` and `Sunset: June 30, 2024` header on all v2 responses immediately.
3.  **Canary Blocking:** Build the kill-switch to block v2 traffic by API key, not globally. This allows us to surgically disable only non-compliant partners while protecting the others.
4.  **Monitoring Dashboard:** Create a real-time view of v2 call volume per partner to trigger manual intervention before auto-blocking.
