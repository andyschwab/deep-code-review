**Decision:** Update the backend software first; do not replace physical display units yet.
**Rationale:** The $85,000 budget and three-engineer team cannot support a simultaneous hardware swap across four hospitals while meeting the November 15th deadline and passing a rigorous external audit. Hardware replacement introduces supply chain variables and physical installation risks that jeopardize the irreversible cutover date. Software updates allow for staged rollout, isolated testing, and immediate rollback if the audit fails, directly addressing the recent security incident.

**Required CMO Approvals:**
1.  **Clinical Risk Waiver:** Explicit sign-off on the 30-minute display blackout window, confirming it occurs during a pre-defined low-volume triage period with manual fallback protocols active.
2.  **Patient Safety Validation:** Approval of the "manual triage board" contingency plan to be used if the new system fails the external security audit or experiences latency post-cutover.
3.  **Data Privacy Clearance:** Confirmation that the new backend architecture isolates patient identifiers from the public-facing display layer, satisfying the remediation requirements of the recent 200-record exposure.

**First Technical Test (Next Hour):**
Execute a **loopback connectivity test** on a single, isolated development server mirroring the production backend.
*   **Action:** Configure the new backend software to ingest a synthetic dataset of 50 fake patient records (generated locally, no PHI).
*   **Verification:** Confirm the system pushes "Wait Time: XX mins" payloads to a local mock display endpoint without attempting any outbound connection to the live hospital network or public internet.
*   **Success Criteria:** The mock display updates correctly within 2 seconds, and network monitoring tools show zero traffic leaving the isolated test VLAN.

**Note:** This approach prioritizes the immutable November 15th deadline by de-risking the physical layer.
**Note:** The security audit must be scheduled immediately upon successful completion of the isolated backend test.
