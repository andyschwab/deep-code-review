**Decision:** Execute a staged rollout beginning with a single-building pilot to validate calibration thresholds before any mass deployment. Do not ship hardware to the remaining fourteen facilities until the pilot confirms false-alarm rates are below 2% over a 72-hour period.

**Figures:** 2,000 rooms / 10 technicians = 200 rooms per technician. To finish by the 30th, each technician must install 10 rooms/day (assuming 20 working days remaining). If the pilot fails and requires individual recalibration, the rework time exceeds the deadline by a factor of 10x, triggering the insurance penalty.

**Workflow Sequence:**
1.  **Pilot Phase (Days 1–5):** Deploy to one wing (50 rooms) in the oldest facility. Install hardware but keep sensors in "monitor-only" mode (no alerts sent to staff).
2.  **Calibration Validation (Days 6–8):** Analyze monitor-only data against known fall simulations and normal movement. Adjust sensitivity thresholds centrally.
3.  **Live Pilot (Days 9–11):** Enable alerts for the 50 rooms. Measure false-positive rate and staff response time.
4.  **Go/No-Go Gate:** If false alarms > 2%, halt and recalibrate. If < 2%, authorize mass deployment.
5.  **Mass Deployment (Days 12–30):** Roll out to remaining facilities in batches of three, applying the validated central calibration profile immediately upon install.

**Owner Sign-Off Required (Calibration Parameters):**
*   **Acceleration Threshold:** The specific G-force magnitude required to trigger an event (e.g., >2.5G).
*   **Orientation Angle:** The degree of tilt indicating a prone position (e.g., >45 degrees for >3 seconds).
*   **Inactivity Timer:** The duration of no movement post-impact before an alert fires (e.g., 30 seconds).
*   **False-Positive Tolerance:** The maximum acceptable number of non-fall alerts per 100 resident-days (e.g., <5).

**Technician Self-Organization (Logistics):**
*   Route planning within assigned facilities to minimize travel time between rooms.
*   Physical mounting height and angle adjustments based on room furniture layout (within the approved variance range).
*   Battery installation and basic LED status verification.
*   Coordination with facility staff for room access times.

**First Concrete Steps for Wireless Mesh Stability (Oldest Building):**
1.  **Site Survey:** Walk the oldest building with a spectrum analyzer to map existing Wi-Fi interference and dead zones before installing any new devices.
2.  **Node Placement Test:** Install five gateway nodes and ten sensor nodes in the identified worst-case locations (basements, thick concrete walls).
3.  **Packet Loss Stress Test:** Run continuous ping tests between nodes and the central gateway for 24 hours while simulating peak network traffic (staff using tablets/phones).
4.  **Topology Verification:** Confirm that if any single node fails, the mesh reroutes data without packet loss greater than 1%.

**Halt Trigger:** If packet loss exceeds 1% during the stress test or false alarms exceed 2% in the live pilot, stop all deployment immediately.
**Fallback Trigger:** If mesh stability cannot be achieved in the oldest building by Day 7, switch to a wired backbone solution for that facility only and proceed with wireless for the others.

*Note: This plan assumes the "oldest building" represents the worst-case infrastructure scenario. If insurance compliance requires 100% of rooms active simultaneously on Day 30, the pilot window must compress to 48 hours, increasing risk.*
