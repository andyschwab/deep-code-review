**The numbers.**
In a one-time purchase model, Lifetime Value (LTV) equals the Average Order Value (AOV) plus the monetized value of referrals, minus variable costs.
*Formula:* `LTV = (Course Fee) + (Referral Rate × CAC Saved per Referral) - Variable Costs`
*Assumption:* We assume variable costs (platform hosting per user, materials) are negligible compared to fixed instructor pay, so we treat the $1,200 fee as gross margin. If variable costs exist, margins worsen.
