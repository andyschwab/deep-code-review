2.  **Selection Decision (Owner: You):** By end of Week 1, you must select the primary vendor based on these non-negotiable criteria:
    *   **Contractual SLA Guarantees:** Specific penalties for downtime or accuracy deviations >5 meters.

2.  **Accuracy Verification (Owner: You):** Review shadow mode reports. You must personally sign off on the accuracy tolerance threshold (e.g., accepting 99.5% match rate) before authorizing the cutover plan.

**Phase 3: Cutover Execution (Weeks 5-6)**
1.  **Staged Rollout:**
    *   *Week 5:* Deploy to 10% of the fleet (low-risk routes). Monitor closely for 48 hours.
    *   *Week 6:* Expand to 50%, then 100% only if metrics hold.
2.  **Final Cutover:** Complete full migration by January 8th, leaving a one-week buffer before the January 15th shutdown for emergency rollback if critical failures occur.
