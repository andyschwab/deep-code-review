### Summary of Defects

1.  **File:** `src/click/exceptions.py`, Line 236 (`FileError.format_message`)
    *   **Issue:** The use of `{filename!r}` introduces `repr()` formatting, wrapping the filename in quotes (e.g., `'file.txt'`). The original code did not include quotes. This breaks existing output format expectations.
    *   **Fix:** Change `{filename!r}` to `{filename}`.

2.  **File:** `src/click/exceptions.py`, Line 148 (`MissingParameter.format_message`)
    *   **Issue:** The separator between the period and `msg_extra` was changed from two spaces (`.  `) to one space (`. `). This is an unintended whitespace regression.
    *   **Fix:** Revert to `f".  {msg_extra}"`.

3.  **File:** `src/click/exceptions.py`, Line 196 (`NoSuchOption.format_message`)
    *   **Issue:** The `ngettext` call passes the comma-separated `possibility_str` to the `{possibility}` placeholder (intended for a single item) even in the singular case. While functionally safe for length=1, it is logically incorrect and fragile for translations that might distinguish between single/multiple formats differently.
    *   **Fix:** Pass `self.possibilities[0]` to `possibility` and the joined string to `possibilities`.
